## 구현 경계와 단순화

새 API·스키마·의존성·확률·보상 수량은 없다. NFT·기보유품·방문·기발급 쿠폰·권리·잔액 계산·멱등키를 바꾸지 않는다. 공유 풀 비복원 추첨·7일 자동 사용도 변경하지 않았다. 과거 BASE/PRISM 쿠폰 문구와 서버 판정은 기존 동작 보존이지 새 정책 확정이 아니다.

홈은 기존 병렬 조회 데이터를 재사용한다. 기존 내용을 화면에 남겨 놓더라도 주 행동은 이번 조회가 끝난 영역만 사용한다. 새 획득은 이전 홈 응답에 없던 수집품 권리 ID 또는 새로 확인한 USED 코인권 ID로만 감지하며 최초 로딩/같은 USED 재조회는 신규로 꾸미지 않는다. 시간 임계값·새 서버 영수증 체계·로컬 보상 지급은 추가하지 않았다. 앱 재시작 뒤 과거 획득 시점을 추측하지 않는 제한이 있다.

코인 개봉은 서버 결과를 받은 뒤에만 시작하며 사용 요청을 재실행하지 않는다. 복구된 결과는 개봉을 반복하지 않고 기존 결과 카드로 간다. `source/opening/result` 어느 단계의 건너뛰기도 결과를 지우지 않는다. 알 수 없는 커스텀 등급은 희귀도를 추측하지 않고 일반 연출을 쓴다. 실제 음향·진동은 기존 사용자 설정을 따른다.
