# O1 점주 운영 동선 점검 (2026-10-09)

## 적용 범위와 현재 화면

- 운영 웹 `/merchant/`은 PR #418 제작기를 기본 화면으로 둔다. 점주 탭은 `방문 보상 만들기 → 방문 확인 → 운영 결과`이며 제작기는 서버의 `MANAGE_ART` 권한과 게시 가능 캠페인만 사용한다(`apps/production-web/merchant.html`, `assets/merchant.mjs`). PR #429의 코인 외형·회전·재질 파일은 변경하지 않았다.
- 방문 확인에서는 고객 QR 확인 → 실제 이용 확인과 이용 식별 번호 입력 → 방문 코드 발급 순서다. 같은 화면에서 발급된 코드의 재발급을 요청할 수 있으나 기존 코드 무효화 확인이 필요하다. 쿠폰을 쓰려면 방문 코드 발급 전에 같은 고객 QR로 조회한다.
- 최근 방문·쿠폰 사용은 서버가 허용한 행만 취소·되돌리기 버튼을 보여 준다. 방문 취소는 사유·선택 메모와 최종 확인을 거치며, NFT 발행 상태와 한국 영업일 제한은 서버가 다시 검사한다. 쿠폰 되돌리기도 최종 확인 및 서버의 10분·권한 검사를 거친다.
- 시연 모바일 점주 화면은 방문 확인이 기본 탭이다. 발급 직후 `잘못이면 방문 취소`가 `오늘·현황`의 해당 방문을 선택해 주며, 취소 사유와 확인 절차를 유지한다(`apps/mobile/src/screens/merchant-home/index.tsx`, `merchant-claim/staff.tsx`, `merchant-claim/staff-reversal.tsx`). `가게 꾸미기`에서 그림 제작 화면과 운영 웹 제작기 주소를 제공한다.

## 이번 동선 개선

- 운영 웹의 방문 확인 화면에 `최근 방문·쿠폰 사용 확인`을 추가했다. 선택한 점포를 결과 화면의 최근 목록·현황에 맞춘 뒤 최근 목록 제목으로 이동하고 키보드 초점을 준다. 두 점포를 운영할 때 다른 점포의 취소 대상을 보는 혼동을 막는다.
- 운영 결과에서는 최근 방문·쿠폰 사용 목록을 현황보다 먼저 배치했다. 목록을 찾기 위한 긴 스크롤을 줄이되 취소 폼, 확인 창, API 요청, 점주·직원 권한은 유지한다.
