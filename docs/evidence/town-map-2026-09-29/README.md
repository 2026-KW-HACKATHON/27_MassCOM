## NOT_RUN

- **에뮬레이터·실폰의 다크 모드와 글자 200% 지도 화면:** 실폰 캡처는 모두 라이트 모드·기본 글자 크기다. 지도 화면의 다크·큰 글자는 화면으로 확인하지 않았다(색 조합과 크기 값은 자동 시험만).
- **TalkBack 낭독:** 핀의 "가게 이름, 도장 받음/아직 없음" 라벨과 길찾기 선택 창의 실제 낭독은 확인하지 않았다(접근성 속성은 자동 시험으로만 검사).
- **웹 대체 경로:** 앱이 거절할 때 `https://map.naver.com`·`https://map.kakao.com` 주소로 넘어가는 동작은 단위 시험(`directions.test.ts`)만 있다. 이 휴대전화에는 두 지도 앱이 모두 설치돼 있어 실기를 하지 못했고, 앱이 없는 기기에서의 확인이 남았다.
- **시연 빌드(Preview 8)의 지도:** 시연 앱 variant에서 핀이 점포 그림 썸네일로 놓인 모습은 확인하지 않았다(개발 빌드에서는 도장 글자가 놓인다). 병합 뒤 Preview 8을 빌드해 확인한다.
- **가게 8곳 초과 넘침 목록·빈 목록·로그아웃 상태 화면:** 로컬 seed의 가게가 네 곳뿐이라 넘침 목록("지도에 다 담지 못한 가게")은 화면으로 보지 못했다. 자리 배정과 9번째부터의 넘침은 `anchors.test.ts`의 자동 시험이다.
- **칩으로 지도에 들어가는 화면:** 01은 칩이 보이는 모습이고, 칩을 눌러 지도 탭이 열리는 촬영은 폴더에 없다(소스 시험은 있음).
- **소유자의 판정:** 그림 지도가 "동네를 한눈에 보게 한다"는 느낌, 핀 배치·크기, 길찾기 흐름의 편의는 사용자 판정이 필요하다.
- **공개 서버·릴리스:** 병합 뒤 Preview 8 APK, 공개 `/open` 안내 갱신, 웹 재배포는 이번 범위 밖이며 하지 않았다.

## 개인정보: 외부 지도 앱 화면을 저장하지 않은 이유

네이버 지도 앱은 주소 검색 결과에 **휴대전화 자신의 현재 위치로부터의 거리**를 함께 보여 주었습니다. 이 앱이 위치를 넘긴 것은 아니고(위 환경 참조) 외부 앱이 자기 권한으로 표시한 것이지만, 그 화면을 캡처하면 촬영자의 위치가 저장소에 남습니다. 그래서 네이버·카카오 외부 앱 화면은 저장하지 않았고, 두 앱이 열린 사실은 "PASS" 표의 육안 확인으로만 기록합니다. 마찬가지로 길찾기 선택 창의 "이 앱은 내 위치를 쓰지 않아요"는 **이 앱**에 대한 문장이며, 사용자가 고른 외부 지도 앱이 자체적으로 위치를 쓰는 것은 그 앱의 권한과 설정을 따릅니다.

## 자동 검사

이 기능의 자동 검사 결과는 [테스트 상태](../../TEST_STATUS.md)에 있습니다. 이 문서를 쓰면서 `npm test --prefix apps/mobile`을 다시 실행해 **477/477 PASS**를 확인했습니다(하늘 동네 개편 기록의 388에서 지도·길찾기·핀 배정·스타일 시험이 더해졌다). 타입 검사·린트·운영/시연 두 variant의 `export:android`, variant 자산 검사, 접근성 semantics 검사는 구현 작업의 보고대로 PASS이며 이 문서를 쓰는 동안 다시 실행하지는 않았습니다. 이 폴더의 화면과 자동 검사는 필수 시험 36개 ID의 상태를 바꾸지 않습니다.
