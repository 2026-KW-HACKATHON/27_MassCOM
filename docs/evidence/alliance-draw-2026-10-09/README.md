# 공유 뽑기·연합 미션·계정 AI 한도 검증

2026-10-09 KST, `fix/ai-image-gap-fixes`의 로컬 개발 웹을 실제 API와 격리 PostgreSQL에 연결해 확인했다. 스크린샷은 실제 브라우저 390×844다. 시연 계정과 가상 점포만 사용했으며 운영 방문·점주 동의·실제 혜택·결제의 증거가 아니다. API의 실제 서버 난수로 추첨했고 결과 등급을 미리 선택하지 않았다.

가게 B의 검수 그림은 저장소의 기존 4등급 WebP 자산을 사용하는 합성 게시물이다. 가게 A는 기존 단색 PNG 시험 게시물, C는 게시 그림 없는 상태다. 이를 새 가게 그림의 품질 검증으로 해석하지 않는다. 기존 앱의 헤더·카드·색상·하단 메뉴를 유지했으며 참고 이미지의 확인·획득·재뽑기 전후 흐름을 비교했다. 자동 테마에 따라 일부 캡처는 어두운 색상이다.

API 단위675/675, 모바일2165/2165, 사이트493/493과 타입·빌드·lint 검사를 통과했다. PostgreSQL 전체 실행597 PASS/3 SKIP 뒤 독립 호스트 시드 환경에서 해당3건을 각각 통과해 고유600건의 통과 근거를 확보했다. 단일 실행600 PASS로 표기하지 않는다.

7일 경계·프리즘 리필·동시 계정·NFT 잠금·기간 내 방문·AI 자정 및60초 잠금 대기는 PostgreSQL 회귀시험으로 검증했다. 실제 Android 기기·소리·진동·유료 OpenAI 생성·새 API/DB/웹/APK 배포는 실행하지 않았다. 운영·시연 키 설정 활성화의 별도 근거는 [설정 기록](../openai-ai-art-enable-2026-10-09.json)이다. 계정 한도와 뽑기·미션 소스는 릴리스 전이다.
