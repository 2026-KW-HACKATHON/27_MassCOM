## 5분 시연 흐름 (390×844 라이트)

다음 순서로 진행했다.

1. 역할 선택
2. 로그인 없이 체험
3. 약관 동의
4. 신규 홈
5. 탐색 목록
6. 가게 상세
7. 테스트 방문
8. 봉투 공개
9. 도감
10. 내 코인·뽑기권
11. 상점·등급 뽑기
12. 마이룸 전시 저장
13. 가게 이웃 방
14. 놀이 허브
15. 게임 1판
16. 내 정보
17. 점주 역할 전환

- **기능:** 모든 단계가 PASS였다. 테스트 방문은 `POST /showcase/test-visits`가 201로 응답했고, 마일리지가 +150 들어왔다.
- **오류:** `console.error`, `pageerror`, HTTP 4xx/5xx가 모두 0건이었다.
- **빈 상태:** 코인 뽑기권과 가게 이웃 방은 시연 데이터가 없어 빈 화면이었다. 가구 6종은 가격 미정이라 살 수 없었다.
