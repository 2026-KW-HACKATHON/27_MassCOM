# 하늘 동네·여권 도장 개편 · Android 에뮬레이터 로컬 실측 (Issue #224)

2026-09-29 KST, 이 Mac의 Android 에뮬레이터에서 [하늘 동네·여권 도장 개편](../../superpowers/specs/2026-09-29-sky-town-redesign-design.md)을 확인한 기록입니다. 이 폴더의 화면은 **로컬 개발 환경**의 것이며 운영·시연 공개 서버, 공개 APK, 실제 점포·방문·쿠폰과 무관합니다. 실제 휴대전화·TalkBack·소유자의 "꾸민 느낌" 판정은 아직 하지 않았습니다(아래 `NOT_RUN`).

## NOT_RUN

- **실제 휴대전화(Samsung SM-S928N)에서 이 브랜치 확인:** 확인 시점에 폰이 연결돼 있지 않았다. 개편 전 Preview 7 설치본은 있으나 이 코드의 설치·화면 확인은 하지 않았다. 계획의 실폰 전후 촬영은 미실행이다.
- **TalkBack 낭독:** 도장 칸·탭 바·마스코트 라벨의 실제 낭독은 확인하지 않았다(접근성 속성은 자동 시험으로만 검사).
- **동작 줄이기 스위치의 시각 확인:** 실행 중 OS 설정을 바꿨을 때 연출이 멈추는 모습은 화면으로 확인하지 않았다(분기와 구독은 단위 시험).
- **시연 빌드의 점포 그림:** 시연 앱 variant에서 점포 그림이 음식점 상세 머리글 배경과 도장 썸네일로 놓인 모습은 확인하지 않았다(시연 export·자산 경계 검사와 소스 시험만).
- **글자 200% 도감·방문 인증 라이트 이미지:** 확인은 했으나 폴더에 넣지 않았다.
- **소유자의 "꾸민 느낌" 판정:** 사용자 판정이 필요하다.
- **공개 서버·릴리스:** 운영·시연 서버와 APK 반영은 이번 범위 밖이며 하지 않았다.

## 자동 검사

이 개편의 자동 검사 결과는 [테스트 상태](../../TEST_STATUS.md)에 있습니다. 모바일 시험은 347/347 PASS입니다(개편 전 276). 타입 검사·린트·운영/시연 두 variant의 Android export와 variant 자산 검사는 구현 작업의 보고대로 PASS이며 이 문서를 쓰는 동안 다시 실행하지는 않았습니다. 이 폴더의 화면과 자동 검사는 필수 시험 36개 ID의 상태를 바꾸지 않습니다.
