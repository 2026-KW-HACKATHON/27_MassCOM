## NOT_RUN

- **실제 휴대전화(Samsung SM-S928N)에서 이 브랜치 확인:** 확인 시점에 폰이 연결돼 있지 않았다. 개편 전 Preview 7 설치본은 있으나 이 코드의 설치·화면 확인은 하지 않았다. 계획의 실폰 전후 촬영은 미실행이다.
- **TalkBack 낭독:** 도장 칸·탭 바·마스코트 라벨의 실제 낭독은 확인하지 않았다(접근성 속성은 자동 시험으로만 검사).
- **동작 줄이기 스위치의 시각 확인:** 실행 중 OS 설정을 바꿨을 때 연출이 멈추는 모습은 화면으로 확인하지 않았다(분기와 구독은 단위 시험).
- **시연 빌드의 점포 그림:** 시연 앱 variant 빌드의 점포 상세 화면에서 점포 그림이 놓인 모습은 확인하지 않았다.
- **소유자의 "꾸민 느낌" 판정:** 사용자 판정이 필요하다.
- **공개 서버·릴리스:** 운영·시연 서버와 APK 반영은 이번 범위 밖이며 하지 않았다.
