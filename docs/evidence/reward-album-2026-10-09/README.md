# Reward Album Browser QA

This evidence folder is generated by `node tests/fixtures/reward-album-rnw/run-qa.cjs`.

The harness imports the real React Native Web components from `apps/mobile/src`:

- `@/acquisition/registration-album`
- `@/screens/shop/grade-draw-machine`
- `@/screens/shop/gacha-machine`

Mocks cover browser boundary modules used outside the reward-flow contract: Expo Router focus/navigation, AsyncStorage, Expo application/constants, audio, haptics, sharing, safe-area, view-shot, html2canvas, and a React Native fixture adapter that re-exports React Native Web while overriding only `useWindowDimensions().fontScale` from the query string for compact-layout simulation. Reanimated, Worklets, and React Native SVG are aliased to their real web-capable source paths, and the harness runs the local Reanimated Babel plugin before esbuild bundles the app sources.

The screenshots and report assertions prove flow wiring, responsive layout, compact 320px/no-overlap layout, simulated 200% font-scale/no-overlap layout, Reanimated web setup in Chromium, registration scale/opacity animation sampling, settled registration visibility, skip-hold behavior, and completion states. They still do not claim Android native haptics, sound, phone font-scale delivery, or physical device animation timing.

The harness does not call app APIs, issue rewards, or claim native/phone QA.
