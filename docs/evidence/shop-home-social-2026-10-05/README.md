# Issue #367 브라우저 화면 증거

2026-10-05 로컬 Expo 웹 번들과 실제 개발 API/PostgreSQL로 확인한 화면입니다. 가게·계정·초대는 검증용 가상 데이터입니다. 화면 밖 흰 영역은 브라우저 미리보기 환경에 포함됐습니다.

- `home-test-ticket.png`: 테스트 방문 1회 후 홈에 가게 뽑기권 1장 표시.
- `shop-silver.png`: 실버 티켓·보상 범위·확률과 초록색 200마일리지 구매 버튼.
- `sound-settings.png`: BGM·효과음 켜기/끄기·음량·진동 설정. 재생·진동 실기 증거는 아닙니다.
- `meal-response.png`: 가게·주소·날짜·12~14시 요청 범위와 수신자가 고른 확정 시간 12:40을 보낸 사람 우편에 표시.

실제 Android의 음향·진동·원격 푸시는 연결 기기와 FCM/EAS 자격 증명이 없어 `NOT_RUN`입니다. Android 번들 생성과 토큰/전송/수신 확인 테스트를 실제 기기 배달 성공으로 해석하지 않습니다.
