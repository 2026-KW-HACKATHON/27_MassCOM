# 광운대 인근 시연 가게 330곳 근거

- 원본: [소상공인시장진흥공단 상가(상권)정보 2026-06-30](https://www.data.go.kr/data/15083033/fileData.do), 공공데이터포털의 이용허락범위 표기 `제한 없음`. [원본 ZIP](https://www.data.go.kr/cmm/cmm/fileDownload.do?atchFileId=FILE_000000003695831&fileDetailSn=1)의 서울 CSV에서 노원구 월계1·2·3동의 `음식` 업소를 추출한 487행 JSON을 사용했다. 추출 JSON SHA-256: `81a38873647eb4f0b0a42d8db7ad5eddf95b421207c0291c34bea529b1431c08`.
- 선택: 기존 월계역 중심 30곳과 순서를 그대로 유지하고, 앱의 광운대 지도 기본 중심 `(37.6206, 127.0567)`에서 가까운 다른 300곳을 추가했다. 새 300곳의 최대 중심 거리 약 857m. 구내식당·유흥주점과 같은 상호·주소 중복은 제외했고, SEMAS 업소 ID 330개는 모두 다르다. `distanceM`은 기존 계약대로 **월계역** 기준 거리다.
- 분포: 총 330곳 중 월계1동 252, 월계2동 42, 월계3동 36곳. 좌표 범위는 위도 `37.6150302937308–37.6341516262236`, 경도 `127.051281704693–127.065286827602`다.
- 재생성: 위 추출 JSON을 `node scripts/build-showcase-wolgye-stores.mjs <JSON 경로>`에 전달한다. 원본 487행 JSON은 대용량 원본 ZIP에서 나온 작업 자료이고 Git에는 넣지 않았다. 재생성 시 487행·기준일·SHA-256을 먼저 확인한다.
- 한계: 2026-06-30 스냅샷이며 현재 영업 여부는 별도 검증하지 않았다. 실제 점주 참여나 방문 보상을 뜻하지 않는다. 운영 DB에는 넣지 않으며, 시연 DB seed는 기존 이름 가드와 충돌 검사를 통과해야 한다.
