## 규칙과 보호

방문 확정 보상은 게임 성공 여부와 관계없다. 게임 완주 3회/10회는 저녁/정원 장면을 해금한다. 재화·쿠폰·보상권·양도 규칙을 추가하거나 변경하지 않았다. 계정별 실행 소유권, 만료·입력 범위·시간, seed 재계산과 완료 재시도를 검사한다. 이는 자동 조작 탐지나 사람의 점수 증명은 아니다.

공간은 실제 보유품만 저장하고 취소된 권리는 읽을 때 제외한다. 친구 열람은 관계/활성 계정 재검사 후 저장한 공간만 노출한다. 계정 삭제는 새 계정 데이터도 제거한다. 새 데이터와 친구 공개 범위에 맞춰 `privacy-2026-10-04`로 갱신했고 이전 동의는 재확인한다. 약관 버전은 유지했다.

## 검증 환경

- 웹: 설치된 Chrome + Playwright, 390×844와 1280×900, 로컬 시연 DB·API를 같은 origin의 미리보기로 제공.
- DB: 별도 `masscom_connected_full_test`, PostgreSQL 16, 루프백 전용 Docker. 실제 운영 DB나 계정을 변경하지 않았다.
- Android: 기존 개발 signing key로 debug APK를 빌드, `kr.masscom.wolgye.dev` 에뮬레이터에 덮어 설치. 실제 폰과 운영/시연 앱은 변경하지 않았다.
- 로컬 설정: Expo 57의 `expo/virtual/env`가 기존 `.env.local` 값을 합치는 현상을 확인했다. 사용자 파일을 내용/권한 그대로 임시 보관해 테스트 환경을 분리했고, 검증 후 SHA-256·권한·mtime을 비교해 원상 복구했다. 에뮬레이터의 글자·전환 설정도 원래대로 돌렸다.

## PASS 근거

- API 단위 403개, 타입 검사/빌드. 새 실행/공간·기존 동의·점주 메뉴 범위 회귀 포함.
- PostgreSQL 전체 403개 중 400 PASS, 3 SKIP. 새 migration, 계정 삭제, 소유권, 재시도, 친구 비공개, 권리 취소를 별도 시험에서도 확인.
- 모바일 1395/1395, 사이트 467/467, 타입 검사/lint PASS. 운영·시연 Android와 웹 export PASS, 각 Android 번들에 자기 API origin만 포함됨을 검사했다.
- 실제 브라우저에서 네 게임을 각각 완주하고 최고 기록/완주/장면 해금을 서버에 저장. 공간 저장과 피드/스토리 파일 다운로드 확인, pageerror 0.
- Native에서 새 개발 앱 실행·공간·놀이, 기본/200% 글자와 모션 감소를 확인. 준비 그림이 세로로 늘어나거나 타이밍 버튼이 화면 아래로 밀리는 문제, 어두운 배경 글자 명암과 큰 글자 빈 공간 안내 겹침을 발견·수정 후 재캡처.

## 배포와 남은 확인

공개 출시·운영/시연 서버 반영·스토어 제출은 `NOT_RUN`. 새 APK 공개와 서버 migration 0042, 웹/앱 처리방침 04 버전을 함께 반영해야 하며, 이전 설치본은 업데이트 안내가 필요하다. 코드 롤백 시 새 사용자 기록이 있는 표를 삭제하지 않는다.

실제 점포 QR·Samsung 새 기능·TalkBack·기기 효과음/진동의 체감·운영자/점주 실제 Google 세션으로 일상 운영은 이번 검증에서 `NOT_RUN`. 자동·로컬 시연 검사와 실제 운영 성과를 합쳐 주장하지 않는다. 새 기능 이름만 있거나 나머지 장르를 후속으로 남긴 상태는 아니다.
