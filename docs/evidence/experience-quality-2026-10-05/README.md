## 획득·착용·다음 탐험

첫 합성 고객은 방문 9건·수집품 6개로 얻은 마일리지 950에서 기존 API의 네 번 개봉 후 150을 보유했다. 상점 UI에서 100을 사용해 [곰과 카페 장식](pack-acquired-decor-390.png)을 얻고 잔액 50·테마 3/3을 확인했다. [미보유 전체 조합](theme-unowned-preview-390.png)은 저장 버튼 없이 참고용으로 표시되며, [전체 소장 조합](theme-owned-preview-390.png)은 명시적인 확정 뒤 세 슬롯이 함께 저장된다.

두 번째 합성 고객의 [수집 전 게임](first-user-games-empty.png)을 확인한 후 기존 방문 코드 발급·교환 API로 첫 방문·코인 1개·마일리지 150을 얻었다. 320×640·라이트·동작 감소에서 UI로 팩을 개봉해 곰과 모자를 얻고, 아래 버튼을 눌러 장착 완료·대표 설정을 확인했다. 수정한 결과 모달은 내부 높이 560px, 내용 955px로 스크롤되고 버튼에 닿는다. [획득 후 상점](shop-after-purchase-320-reduced-motion.png), [코인까지 전시한 홈](final-home-320-light-reduced.png)을 참조한다. 마지막 홈은 좁은 화면의 제목을 다음 행 버튼과 분리한 보정본이다.

[친구 공간](friend-theme-room-390.png)에서도 같은 카페 장비가 보인다. 전시 코인을 누르면 [가게의 1·3·5회 획득 조건](friend-coin-merchant-goal.png)이 열리며 [내 방문 목표 저장](friend-goal-saved.png)으로 이어진다. 이미 완료된 첫 방문 목표는 로컬 QA 저장 상태만 복원한 시험에서 목표 달성으로 표시하고, 새 목표 선택→B 방문 목표 저장을 확인했다. 이 복원은 제품 API가 완료 목표를 새로 수락했다는 증거가 아니다.

## 이미지·영상과 상태

[Android 증거](native-evidence.md)는 네 동행 착용, 실제 피드·스토리 PNG/H.264, 갤러리, 캐시 반복 일치, 취소·포커스 복귀 및 글자 배율 2.0을 구분한다. [웹 피드 PNG](web-feed.png)와 [웹 MP4](web-feed.mp4)는 실제 내보내기 버튼으로 만든 다운로드 파일이다. MP4는 AVC, 1080×1350, 4.104초, 1,469,576바이트이며 정확한 시점으로 디코딩한 세 프레임이 다르다. [미디어 검사](web-media-proof.json)를 참조한다. CUA의 다운로드 이벤트는 시간 초과했지만 OS 파일과 저장 완료 UI를 확인했다.

상점 요청을 개발 도구로 막아 [연결 오류](shop-network-error-320.png)를 재현하고, 차단 해제 후 다시 불러오기로 [잔액·소유 복구](shop-retry-restored-320.png)를 확인했다. 네트워크 차단·테마·동작 감소·화면 크기 임시 설정은 복구한다. 브라우저에는 기존 세션 검증기를 통과하는 두 합성 고객의 임시 세션을 로컬에 넣었다. 실제 Google 로그인·운영 권한 증거가 아니며 세션/계정/환경 원본을 이 폴더에 복사하지 않았다.
