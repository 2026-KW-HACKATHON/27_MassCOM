# 친구: 코드·QR·링크로 추가하고 여권 보기 · 실제 휴대전화 로컬 실측 (Issue #230)

2026-09-29 KST, Samsung 휴대전화(SM-S928N)에서 [친구 설계](../../superpowers/specs/2026-09-29-friends-design.md)(D-047)의 앱 화면을 확인한 기록입니다. 이 폴더의 화면은 **로컬 개발 환경**의 것이며 운영·시연 공개 서버, 공개 APK, 실제 사용자·점포·방문과 무관합니다. 화면의 친구 코드와 별명은 모두 일회용 로컬 DB의 시험 계정 것입니다.

## 같은 실측에서 확인했지만 캡처하지 않은 것

- 소문자 코드 입력이 자동 대문자로 바뀌어 추가됨. 별명 `go.kr/x`는 서버 검증 오류 문구로 거절되고 `Sky7`은 저장되어 상대 계정 응답에 반영됨.
- 끊은 친구 계정이 내 코드로 다시 추가하면 404(없는 코드와 같은 응답).
- 잘못된 `#friend=BADC0DE1` 링크는 친구 탭으로 가서 "링크의 친구 코드가 올바르지 않아요."를 보임.
- `#merchant=<가게 id>` 링크는 음식점 상세로 열리고, `#merchant=..%2F..%2Fsettings`는 "찾을 수 없는 음식점"으로 끝남.
- 친구 탭을 떠났다 돌아오면 지난 추가 결과 안내가 지워짐.
