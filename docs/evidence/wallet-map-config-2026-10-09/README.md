# 시연 지갑·지도 설정 복구 — 2026-10-09

[Issue #447](https://github.com/2026-KW-HACKATHON/27_MassCOM/issues/447), [PR #448](https://github.com/2026-KW-HACKATHON/27_MassCOM/pull/448). [키·주소를 제외한 결과](results.json).

## 원인과 수정

- 실제 Samsung 설치 APK에 TMAP/NAVER 공개 지도 ID가 없었다. 시연 빌드의 입력 검사와 APK/AAB의 설정·번들 검사를 추가했다.
- 기존 로컬 TMAP 키는 공급자에서 `403 INVALID_API_KEY`로 거절됐다. 콘솔에 재발급된 현재 키를 Git 밖 설정에 반영한 뒤 같은 공개 주소 호출은 `200`·후보1건을 반환했다. 최종 APK는 실제 TMAP 로고·타일을 표시했다. 이전 키를 넣은 첫 수정 APK에서는 네이버 대체 타일도 확인했다.
- 시연 앱은 Reown ID를 무조건 비웠다. `MASSCOM_SHOWCASE_REOWN_PROJECT_ID` → Expo extra → 설치 패키지별 런타임으로 전달하고 운영 ID 자동 상속은 차단한다. 새 프로젝트는 공급자 요금제 한도로 생성되지 않아 소유자가 기존 프로젝트 공유를 선택했고, 콘솔 허용 목록에 `.demo`를 추가했다.
- 실제 지갑 선택창과 `CONNECTED` / `BASE_SEPOLIA`를 확인했고 최종 APK 업데이트 후에도 연결이 복원됐다. 주소 확인은 `UNVERIFIED`로 남겼다. 서명·자산 이동은 수행하지 않았다.

## 검증 경계

실기 APK는 `f07637eb`이며 휴대폰 설치 파일 SHA-256이 산출물과 일치한다. 이후 병합한 `c3c41bf3`의 모바일2231·타입·lint를 확인했지만, 함께 병합된 다른 작업의 우표 영상 기능을 이번 APK 실기 수용으로 해석하지 않는다. 소유자의 기존 시연 로그인·기록을 유지하는 교체 설치만 했다. 실제 GPS·현장 방문·쿠폰 사용·지갑 서명·공개 배포·Play는 NOT_RUN이다. 실제 키·지갑 주소·원시 화면·APK는 Git에 저장하지 않는다.

네이버 클라우드 결제수단은 이미 등록돼 있음을 콘솔에서 확인했다. 카드·청구 설정과 DNS는 변경하지 않았다.
