# 획득 결과와 도감 등록 확인

2026-10-09 사용자 요청. 보상 전체 요약 뒤 새 물품이 도감 칸에 자리 잡는 모습을 보여 주고, 다시 무엇을 얻었는지 확인하는 마무리를 추가한다. 첨부 동영상은 참고 자료로만 읽었으며 원본 영상·타사 카드 이미지를 앱 자산이나 저장소에 복사하지 않는다.

## 구현과 수용 기준

| 경로 | 결과 확인 | 도감 등록과 다음 행동 |
| --- | --- | --- |
| 등급 전체 뽑기 | 서버가 확정한 보상 하나·종류·등급·중복·잔액 유지 | 등록 확인 뒤 코인은 해당 도감 칸, 캐릭터/꾸미기는 기존 설정 행동 |
| 이전 상자 결과 복구 | 마일리지·옷·캐릭터·추가 꾸미기의 전체 요약 유지 | 수집품만 등록 확인, 마일리지는 도감 품목으로 만들지 않음 |
| 가게 코인권 | 실제 이름·그림·총 수량·방문/뽑기 출처 | 신규/중복 확인 뒤 받은 코인 도감 칸 또는 마이룸 |
| 코인 재뽑기 | 반환된 코인 이름·수량·이전 요청 복구 보존 | 새 코인은 그림과 함께 등장·확인, 같은 코인을 돌려받으면 신규로 표시하지 않음 |

공통 등록 화면은 기존 팔레트의 종이 칸과 도장을 쓰며 신규 물품만 작게 등장해 커지고 정착한다. 연출 건너뛰기는 완성 상태만 보여 주고 결과를 지우지 않는다. 결과와 등록 화면은 사용자 입력까지 유지한다. 움직임 감소는 정지 화면으로 같은 정보를 전달한다. 결과를 다시 확인하는 동작은 새 보상을 지급하지 않는다.

코인의 기준 키는 `publicationId + gradeId`다. 등급 뽑기의 신규 여부는 서버 `duplicate`, 가게권은 확정 수량과 `replayed`, 재뽑기는 요청 전 보유 목록·회수 대상·`replayed`를 함께 사용한다. 이전 요청 복구나 판정 근거가 없는 경우 신규라고 추측하지 않는다. 도감 이동 매개변수는 위치 안내에만 사용하고 실제 서버 보유 수량이 있는 칸만 강조한다.

## 검증 경계

공통 고객 코드이므로 운영·시연 앱 모두에 적용된다. 실제 운영 API/DB·보상 확률·재화 원장은 변경하지 않는다. 브라우저 검증은 로컬 합성 응답으로 실행하는 React Native Web 화면이며 실제 휴대전화의 진동·소리·센서 체감과 구분한다. 현재 ADB에 연결된 기기는 없다. 운영 배포와 APK 설치 수용은 이번 작업 범위에 포함하지 않는다.
