# 제품 요구사항

## 목적과 성공 기준

월계1동 이용자가 익숙한 가게 밖의 지역 음식점을 발견하도록 돕고, 실제 이용 인증을 방문 도감과 선택적 NFT 수집으로 연결합니다. 매출 상승은 검증 전 가설이며, 초기 성공은 유효 인증 완료율·점주 처리 시간·지갑 연결 완료율·NFT 최종 등록률·다음 점포 탐색 행동으로 측정합니다.
