# 전체 경험 품질 개선 보고서

> Issue #373 · 기준 커밋 `0ce3114c` · 브랜치 `feat/experience-quality`
> QA 범위: 로컬 시연 데이터와 자동화 CUA 화면 플레이. 실제 사용자·실기 검증이나 공개 배포 상태를 뜻하지 않는다. 통합 상태는 이 브랜치의 PR 검사·병합 기록에 따른다. 공개 배포는 별도다.

## 바꾼 이유와 결과

기존에는 게임이 방문·수집품과 느슨하게 연결되고, 캐릭터 위에 문자나 단순 도형을 장비처럼 얹어 보였으며, 홈에서는 동행이 반복되는 동안 실제 수집품이 작게 밀려 있었다. 네 게임의 조작 결과도 다음 장면에 충분히 남지 않았다. 이번 변경은 새 기능의 개수보다 **가게와 수집품이 놀이의 재료가 되고, 조작한 결과가 장면과 기록으로 이어지며, 획득한 물건을 실제로 보고 착용하는 흐름**을 개선하는 데 초점을 맞췄다.

네 게임은 서로 다른 판단을 유지한다. 쌓기는 놓은 위치와 겹친 폭을 다음 층에 전달하고, 기억은 맞춘 수집품을 도감 장면으로 남긴다. 배달은 출발 가게부터 운반 화물과 도착까지 한 장면으로 보여준다. 주문은 공개된 주문표에 맞춰 여러 물건을 준비하며, 잘못 만든 꾸러미를 되돌릴 수 있다. 보유 수집품이 없을 때는 연습용 장면으로 시작한다. 점주가 게임 콘텐츠를 따로 입력하는 구조는 추가하지 않았다.

## 실제 플레이에서 확인한 변화

로컬 시연 데이터로 자동화 CUA 플레이를 수행해 네 게임의 조작, 결과, 기록을 확인했다. 이는 실제 사용자의 재미나 숙련도를 평가한 결과는 아니다.

| 게임 | 확인된 플레이 결과 |
| --- | --- |
| 쌓기 | 510점으로 6층을 완주했고 남은 폭은 20%였다. 놓은 위치와 오차가 다음 구조에 이어졌다. |
| 기억 | 600점으로 6쌍을 찾아 도감 카드를 남겼다. 별도 시간초과 실행은 185점·6쌍 중 2쌍에서 끝났다. |
| 배달 | 1,200점으로 소포 1개를 건강도 3, 충돌 없이 배달해 배지를 받았다. 별도 재시도는 165점·12구간 중 2구간에서 끝났고 건강도 3·충돌 0이었다. 기존 최고 1,200점·완주 1회·배지는 유지됐다. |
| 주문 | 1,090점을 얻고 주문 4건, 물건 12개를 처리했다. 잘못 제출한 주문을 되돌리고 비운 뒤 역순으로 다시 준비하는 흐름도 실행했다. |

위 결과는 최신 게임 UI를 내보낸 뒤 수행한 로컬 화면 플레이 관찰이다. 배지 보존 수정은 소스와 추가 검사에서도 확인했다.

## 그림과 소장품 경험

아홉 동행의 기존 정체성과 원화는 보존하고, 실제 투명 PNG 착용 원화에 네 가지 표정·행동 프레임을 마련했다. 모자·소품·가방·공간 장식 21종, 배지 문양 7종, 테마 팩 3종도 저장소에 포함된 래스터 아트로 교체했다. 글리프를 아이템 그림처럼 쓰지 않는다. 기존 캐릭터 원화에 붙어 있던 소품을 제거한 착용 원화를 사용하고, 가방은 뒤, 모자와 손 소품은 앞뒤 앵커에 맞춰 합성한다.

공통 그림 합성과 착용은 홈·게임·공간·공유가 같은 자산을 소비하도록 연결했다. 기존 네 캐릭터(토끼·고양이·부엉이·호랑이)의 홈/공간 착용 화면과 네이티브 PNG 및 4초 H.264 영상 합성을 확인했다. 이미지 캐시 재생성 결과는 원본과 바이트 단위로 같았고, 취소 후 포커스 복귀 때 새 내보내기가 생기지 않았다. 둥근 코인과 배지, 바닥·선반 접촉 그림자도 합성에 반영했다.

별도 합성 빈 계정은 방문·코인·마일리지 0에서 시작했다. 게임 허브 연습 진입을 확인한 뒤 기존 API 첫 방문으로 코인 1개·마일리지 150을 받고, 브라우저 UI에서 100 마일리지 브론즈 뽑기로 카페 곰과 브론즈 모자를 얻어 잔액 50이 됐다. 미보유 골드 팩은 전체 미리보기가 열리고 적용 동작 없이 닫혀도 소유/장착 상태가 바뀌지 않았다. 보유 카페 테마는 3칸 미리보기 뒤 한 번 명시적으로 적용해 장착 표시 3개를 확인했다. 친구 공간에서 같은 호랑이·카페 모자·소품·커피 트레이를 확인했다. 별도의 QA 완료 목표 A fixture는 소유권이나 실제 방문을 만들지 않는다. 홈에서는 완료 목표 두 개와 다음 목표가 표시됐고, “선택”으로 공간 화면에 가서 목표 B를 저장해 안내 문구를 확인했다. 홈으로 돌아온 뒤 곰·코인과 이전 목표가 활성 목표로 남지 않은 상태를 확인했다. 320px 라이트 화면에서 제목이 단어 단위로 자연스럽게 줄바꿈되는 최종 배치도 확인했다([홈 캡처](evidence/experience-quality-2026-10-05/final-home-320-light-reduced.png)). 화면 증거: [빈 계정 게임 허브](evidence/experience-quality-2026-10-05/first-user-games-empty.png), [미보유 미리보기](evidence/experience-quality-2026-10-05/theme-unowned-preview-390.png), [보유 테마 미리보기](evidence/experience-quality-2026-10-05/theme-owned-preview-390.png), [친구 공간](evidence/experience-quality-2026-10-05/friend-theme-room-390.png), [저장한 방문 목표](evidence/experience-quality-2026-10-05/friend-goal-saved.png).

웹 공유 UI에서 PNG와 MP4 저장 확인을 받고 실제 다운로드 파일을 확인했다. MP4는 1,469,576바이트, AVC1 1080×1350, 4.104초, 19.003fps였고 저장된 세 프레임은 모두 디코드되며 서로 달랐다([저장 완료 UI](evidence/experience-quality-2026-10-05/web-video-saved-ui.png), [영상](evidence/experience-quality-2026-10-05/web-feed.mp4), [프레임 0](evidence/experience-quality-2026-10-05/web-feed.mp4-0.png), [프레임 1](evidence/experience-quality-2026-10-05/web-feed.mp4-1.png), [프레임 2](evidence/experience-quality-2026-10-05/web-feed.mp4-2.png)). 이 뽑기와 소유/친구 흐름은 로컬 브라우저 UI에서 확인했다. Android 네이티브 구매는 실행하지 않았다.

## 회귀와 경계

새 앱은 `rulesVersion 2`를 명시해 실행하고 이전 앱의 버전 없는 요청은 규칙 1로 처리한다. 선택한 버전은 서버에 저장해 종료·재시도 판정을 고정한다. 이전 실행과 점수는 구분한다. 기존 완주·배지·해금 권리는 유지하며 옛 최고 점수를 새 규칙 점수와 직접 비교하지 않는다. 서버 시드, 입력 간격, 소유권 확인, 동일 실행 재시도와 삭제 경계도 유지한다. 운영/시연 데이터 경계와 기존 점주 캠페인·직원·방문 CSV·FCM 범위는 이번 변경으로 넓히지 않았다. 배포 시에는 버전 협상을 지원하는 API를 먼저 모든 대상에 적용한 뒤 새 앱·웹을 적용한다. 이전 서버는 새 요청의 버전 필드를 거절하므로 공개 배포를 혼합 상태의 검증으로 간주하지 않는다.

실제 QA는 로컬 전용 `masscom_quality_373_test` 데이터베이스와 시연 API에서 진행했다. 게임 플레이에는 방문 9건·수집품 6개·마일리지 950인 합성 계정을, 별도 획득 여정에는 방문·코인·마일리지 0으로 시작한 두 번째 합성 계정을 사용했다. 브라우저 세션 fixture는 localhost 전용(mode 0600)이며 운영 DB와 공개 서버는 변경하지 않았다. 실제 Google 로그인은 수행하지 않았다.

## 검증 범위와 남은 일

- API 단위 테스트 482개, 집중 PostgreSQL 테스트 5개, 타입 검사와 빌드가 통과했다. 전체 PostgreSQL 실행은 446개 중 443개 통과, 3개 건너뜀, 실패 0개다.
- API 단위 482개, PostgreSQL 443개 통과·3개 건너뜀·실패 0개, 사이트 508개, 모바일 전체 1,545개 통과. 최종 모바일 타입 검사·린트도 통과했으며 PR CI는 PR 검사·병합 기록에 따라 갱신한다. 최신 UI를 내보낸 뒤 환경 설정과 파일 상태가 원래대로 복구된 것을 확인했다.
- Android 에뮬레이터에서는 글자 크기 2배의 홈·상점·옷장·게임 준비/결과 화면과 밝은/어두운 화면을 확인했다. TalkBack, 실제 기기, 실제 Google 로그인은 실행하지 않았다.
- Android 공유 화면에서 1080×1350 및 1080×1920 PNG, 프레임 변화가 있는 4초 H.264 영상과 저장/취소 동작을 확인했다. 웹 PNG/MP4 다운로드도 확인했다. 스탬프/톱니 모양 등 다른 코인 형태, Instagram 게시와 실기 재생은 확인하지 않았다.
- 뽑기 결과 모달은 320×640 라이트·`prefers-reduced-motion: reduce`에서 애니메이션 건너뛰기, 560px 실제 높이 안에서 955px 콘텐츠 스크롤, “장착” 버튼과 “장착완료” 문구, 대표 버튼으로 닫기를 확인했다. 상점 GET 차단 시 한국어 연결 실패([화면](evidence/experience-quality-2026-10-05/shop-network-error-320.png)·[복구](evidence/experience-quality-2026-10-05/shop-retry-restored-320.png))를 거쳐 다시 불러오면 잔액 50과 보유 곰이 복원됐다. 완료 목표 A QA fixture는 홈에서 완료 목표 2개와 다음 목표를 보여주고, 공간에서 B 저장 뒤 안내 문구를 표시했다. 관련 소스 시험 70개 통과. 실제 기기·TalkBack·효과음/진동 체감·실사용자 시험과 공개 서비스 배포는 `NOT_RUN`이다. 실수신 FCM, Android 네이티브 구매/다른 게임 장르/스탬프·톱니 코인 형태, Chrome WebM fallback도 확인하지 않았다. 브라우저 구매 검증은 Android 네이티브 구매 검증을 대신하지 않는다.

변경 전 화면은 현재 실행본과 섞지 않도록 별도 기록한 Issue #371 당시 캡처다. 최신 로컬 캡처와 합성물은 [경험 품질 증거 폴더](evidence/experience-quality-2026-10-05/)에 있으며, 임시 QA 세션 파일과 계정 상태 원본은 공개 증거에 포함하지 않았다.
