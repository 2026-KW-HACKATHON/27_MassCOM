월계 마스코트 계정 삭제 안내

개인정보처리방침

월계 마스코트는 음식점 탐색·방문 인증·수집품 기능에 필요한 정보만 처리하며, 사용자 개인키나 복구 문구를 요구하거나 저장하지 않습니다.

현재 상태: 이 서비스는 Google Play 일반 공개 전 개발·검증 단계입니다. 실제 일반 공개 전 보관 기간, 처리 위탁 계약과 법률 검토 결과를 반영해 이 문서를 갱신합니다.

1. 처리하는 정보

  • 계정: Google 로그인이 제공하는 안정적인 계정 식별자, 로그인·재인증 및 세션 상태
  • 서비스 이용: 방문한 점포·캠페인, QR 인증과 보상 처리 상태, 도감 및 계정 삭제 요청 상태(접수·취소·처리 날짜, 접수번호의 해시)
  • 선택적 지갑 연결: 공개 지갑 주소, 요청 체인, nonce, 주소 통제 확인 결과와 연결 버전
  • NFT 발행: 수령 주소, 거래 해시, 계약 주소와 token ID 등 중복 방지·발행 확인에 필요한 정보
  • 친구 기능: 별명, 친구 코드, 친구 관계, 친구를 끊은 기록(다시 추가하지 못하게 하는 차단), 친구 코드 입력 실패 기록
  • 방문·쿠폰 되돌리기 기록: 직원이 잘못 확인한 방문을 취소하거나 쿠폰 사용 처리·발급을 되돌릴 때 남는 상태(취소·무효), 고른 사유(정해진 목록), 선택 메모(100자 이하), 처리한 직원·관리자의 계정 식별자와 처리 시각
  • 가게 그림: 점주가 AI 가게 그림을 요청할 때의 요청 기록(요청자 계정 식별자, 진행 상태, 만들어진 시안·최종 그림)과 가게가 고른 대표 그림

Google 비밀번호, 외부 지갑 비밀번호, 개인키, 복구 문구는 처리하지 않습니다. 서명은 주소 통제 확인에만 사용하며 자산 송금·승인 권한을 요청하지 않습니다.

2. 이용 목적

  • 음식점 탐색, 점주 확인, 일회용 QR 방문 인증과 보상권 발급
  • 로그인 상태와 점주·직원 권한 관리, 중복·부정 이용 방지
  • 선택한 사용자의 외부 지갑 주소 확인과 Base Sepolia NFT 발행·복구
  • 친구 코드로 서로 추가하고 친구에게 내 탐험 여권과 순위 보여 주기
  • 직원이 잘못 처리한 방문·쿠폰을 되돌리고, 누가 언제 왜 되돌렸는지 남겨 부정 이용과 처리 실수를 가려내기
  • 점주가 요청한 AI 가게 그림 생성과 하루 횟수·월 예산 한도 관리
  • 계정 삭제, 장애 대응, 보안 감사와 서비스 품질 검증

3. 친구 기능과 친구에게 보이는 정보

친구는 서로 코드를 주고받아 만들며, 코드를 아는 사람만 추가할 수 있습니다. 전체 사용자 검색과 앱 안 메시지는 없습니다.

  • 별명과 친구 코드: 처음 친구 화면을 열면 기본 별명(“탐험가 XXXX”, 코드와 관계없는 무작위 글자)과 헷갈리는 글자(0·O·1·I)를 뺀 8자리 친구 코드가 만들어집니다. 별명은 언제든 바꿀 수 있고, 코드는 언제든 새로 만들 수 있습니다. 새 코드를 만들면 예전 코드로는 더 이상 추가할 수 없고 지금 친구는 그대로입니다.
  • 친구에게 보이는 정보: 별명, 메달 3종의 등급, 배지 수(9개 중), 가본 가게의 이름과 친구 순위만 보입니다. 방문한 날짜·시각·횟수, 쿠폰, 지갑 주소와 NFT, 계정 식별자, 이메일은 친구에게 보이지 않습니다.
  • 하루 늦게 반영: 친구에게 보이는 메달·가게·순위는 한국 날짜 기준 어제까지의 방문만 셉니다. 오늘 다녀온 가게는 다음 0시(한국 시간)부터 보입니다. 다만 친구가 매일 확인하면 새 가게가 어느 날 목록에 생겼는지로 그 가게를 다녀온 날을 짐작할 수 있습니다.
  • 친구 끊기: 친구를 끊으면 양쪽 화면에서 관계와 여권이 사라집니다. 끊은 사람의 계정에는 상대가 이 계정으로 다시 추가하지 못하게 하는 차단 기록이 남습니다. 차단은 계정 기준이라 코드를 새로 만들어도 유지되고, 끊은 사람이 나중에 그 친구를 다시 추가하면 풀립니다. 다만 상대가 다른 계정으로 로그인하면 이 차단은 적용되지 않습니다. 이미 현재 코드를 아는 상대가 다른 계정으로 다시 추가하지 못하게 하려면 코드를 새로 만들어야 하며, 앱은 친구를 끊은 직후 코드 바꾸기를 권합니다.
  • 코드 입력 제한: 코드 입력이 계정당 10분에 10회 실패하면 그 뒤(11번째 시도부터)에는 무차별 대입을 막기 위해 잠시 입력을 제한하며, 이를 위해 실패 시각을 기록합니다.
  • 공유: 친구 코드 공유와 가게 추천은 기기의 공유 화면으로 링크를 내보내며 앱이 직접 메시지를 보내지 않습니다. 친구 코드는 링크의 # 뒷부분에 담겨 브라우저가 서버로 보내지 않으므로 웹 서버 접속 기록과 링크 미리보기에 남지 않습니다. 다만 코드 공유 문구에는 코드가 일반 글자로도 들어 있어, 그 문구를 보내는 메신저 앱과 서비스는 코드를 볼 수 있습니다.

4. 외부 서비스와 공개 장부

운영 과정에서 Google 로그인, Reown 지갑 연결, Base 블록체인, AWS API·DB 호스팅, Vercel 정적 문서 호스팅, OpenAI 이미지 API를 사용합니다. 각 서비스는 자체 정책에 따라 정보를 처리할 수 있습니다.

  • OpenAI(미국): 사장님 AI 가게 그림 생성. 가게 이름·메뉴 이름만 보내고 계정·고객·점주 개인정보는 보내지 않음. user 값으로 가게 id의 해시만 보냄. OpenAI API 기본 정책상 학습에 쓰지 않고 남용 감시 목적으로 최대 30일 보관.

국외 이전(개인정보 보호법 제28조의8): 가게 그림을 만들 때 가게 이름과 메뉴 이름이 미국에 있는 OpenAI 서버로 전송됩니다. 개인사업자의 가게 이름은 사람을 알아볼 수 있는 정보가 될 수 있으므로 국외 이전 정보로 안내합니다.

  • 이전 항목: 가게 이름과 메뉴 이름(최대 5개)입니다. 두 단계 모두 user 값으로 가게 id의 해시만 함께 보내며, 계정·고객·점주 개인정보는 보내지 않습니다.
  • 이전 국가·시기·방법: 미국으로, 점주가 앱에서 아래 버튼을 눌러 요청할 때에만 옮겨집니다. 앱의 요청을 받은 서버가 OpenAI 이미지 API를 호출하는 방식으로 암호화된 연결(HTTPS)을 통해 네트워크로 전송합니다. 요청하지 않으면 아무것도 전송되지 않습니다.
  • 전송이 일어나는 버튼: “AI 시안 받기”와 “새 시안 받기”는 가게 이름과 메뉴 이름으로 시안 네 장을 요청합니다. “이 시안으로 고급 그림 만들기”와 “이 시안으로 고급 그림 다시 만들기”는 점주가 고른 시안 한 장(OpenAI가 만든 그림)과 고정된 안내 문장만 다시 보내며, 이때는 가게 이름과 메뉴 이름을 다시 보내지 않습니다.
  • 받는 자와 연락처: OpenAI(미국)입니다. 연락처는 OpenAI 개인정보 처리방침에 적힌 문의처를 따르며 OpenAI 개인정보 처리방침에서 확인할 수 있습니다.
  • 이용 목적과 보유 기간: 가게 그림 생성이 목적이며, 위 OpenAI 항목대로 학습에 쓰지 않고 남용 감시 목적으로 최대 30일 보관됩니다.
  • 거부 방법과 효과: 위 버튼을 누르지 않으면 이전은 일어나지 않으며 별도 신청은 필요 없습니다. 거부하면 사장님 AI 가게 그림 기능만 쓸 수 없고 음식점 탐색·방문 인증·도감 등 나머지 서비스는 그대로 이용할 수 있습니다.

실제 NFT가 발행되면 지갑 주소, 거래 해시, 계약 주소, token ID가 공개 블록체인에 남습니다. 개인정보·주문번호·정확한 식사 시각은 NFT 메타데이터나 공개 장부에 넣지 않습니다.

NFT 메타데이터는 누구나 읽을 수 있는 공개 주소(https://masscom.kr/nft-metadata/…)에 있으며 가게 이름, 가게의 동네(행정동)·업종, 방문 단계(예: 3번째 방문), 캠페인 이름과 가게 그림만 담습니다. 이 값들은 사람이 아니라 가게에 대한 정보이고, 발행이 확정될 때 고정되어 뒤에 가게 정보가 바뀌어도 이미 발행한 NFT의 메타데이터는 바뀌지 않습니다. 가게 주소, 방문·발행 시각, 주문·결제, 계정·지갑 정보는 메타데이터에 넣지 않습니다.

5. 보관과 삭제

삭제 요청과 처리 기한: 웹 삭제 안내 페이지에서 앱에서 쓴 Google 계정으로 로그인해 삭제를 접수하면 접수번호를 한 번 보여 드립니다. 접수·취소·접수번호 다시 받기는 최근 10분 안에 한 로그인이 있어야 하며, 그보다 오래된 로그인이면 다시 로그인하도록 안내합니다. 접수한 뒤 24시간은 취소할 수 있고, 그 뒤 운영자가 확인해 접수 뒤 7일 안에 처리합니다. 처리하면 계정이 사라지므로 접수번호만이 처리 결과를 확인할 수 있는 방법입니다. 처리(또는 취소·거절)하면 접수 기록에서 계정 식별자를 지웁니다. 그 뒤에도 남는 것은 접수번호의 해시, 접수·취소 마감·처리 기한·취소·처리 날짜, 처리 결과, 접수 경로(웹 또는 시연 앱), 처리한 방식(관리자 웹 또는 시연 서버 운영자 이름), 운영자가 처리하지 않기로 할 때 직접 적은 사유이며, 처리·거절한 사실은 감사 기록(요청 번호와 처리한 운영자)으로도 남습니다. 처리 기한 7일은 운영자가 직접 처리해야 지켜지는 약속이라 자동으로 보장되지 않으며, 관리자 목록이 기한을 넘긴 요청을 표시해 확인합니다. 접수번호로 조회하면 기한이 지난 요청에 "처리 기한이 지났어요. 문의해 주세요."가 표시됩니다. 접수번호가 생기기 전에 접수된 요청(접수번호가 없는 요청)은 처리하지 않고, 접수한 분이 다시 접수하면 접수번호와 함께 24시간 취소 기간·7일 처리 기한이 그때부터 새로 시작합니다. 시연 앱은 앱 안에서 같은 방식으로 접수합니다. 처리 결과에 이의가 있으면 문의 이메일로 알려 주세요.

계정 삭제가 완료되면 로그인 세션은 기록째 삭제하고 지갑 연결을 끊고, 미전송 발행 작업을 취소하며 계정 식별자를 비식별 별칭으로 교체합니다. 방문 기록, 쿠폰(이미 사용한 쿠폰 포함), 캠페인 참여 기록, QR 수령 기록, 지갑 연결 주소 기록은 삭제하지 않고 계정 식별자만 비식별 별칭으로 바꿔 남깁니다(발급 수·정원 집계, 사용 감사, 중복 발행 방지와 장부 대조용이며, 지갑 주소 자체는 별칭에 붙어 남습니다). 별명·친구 코드·친구 관계·친구를 끊은 기록(내가 끊은 기록과 나를 끊은 기록 모두)·코드 입력 실패 기록은 같은 처리에서 지워지며 가명 처리로 남기지 않습니다. 제출되었거나 확정된 거래와 NFT 기록은 중복 발행 방지와 공개 장부 대조를 위해 보존될 수 있습니다. 블록체인에 이미 기록된 정보는 서비스가 삭제할 수 없습니다.

방문·쿠폰 되돌리기 기록: 취소한 방문, 무효로 한 쿠폰, 사용을 되돌린 쿠폰은 지우지 않고 상태·사유·처리자·시각을 남깁니다. 되돌린 결과가 보상과 쿠폰 규칙에 맞는지 다시 확인하고 같은 방문이 두 번 세어지지 않게 하려는 것입니다. 사유는 정해진 목록에서 고르고 선택 메모는 100자 이하이며, 메모에 이메일·웹 주소·긴 숫자열(전화번호 등)이 보이면 서버가 거절합니다. 이름·주소 같은 그 밖의 개인정보는 자동으로 걸러내지 못하므로 직원에게 적지 않도록 화면에서 안내합니다. 직원 화면에는 고객의 계정 식별자나 이메일 대신 점포마다 다른 짧은 가림 표시만 보입니다. 처리한 직원·관리자 계정을 삭제하면 이 기록의 처리자 식별자는 같은 처리에서 비식별 별칭으로 바뀌고, 고객 계정을 삭제하면 방문·쿠폰의 고객 식별자가 비식별 별칭으로 바뀝니다. 이 기록의 구체적인 보관 기간은 아직 정하지 않았습니다.

가게 그림 요청 기록의 요청자 계정 식별자는 계정 삭제 때 비웁니다. 점주가 가게 그림으로 적용한 그림은 가게 자산이므로 삭제하지 않고 가게에 남깁니다.

  • 적용하지 않은 라운드: 만든 지 30일이 지난 라운드는 그 가게의 새 시안 요청이 받아들여질 때 함께 삭제합니다. 정해진 시각에 따로 지우는 작업은 아직 없으므로, 그 가게가 새 시안을 요청하지 않으면 남아 있을 수 있습니다.
  • 적용한 라운드: 적용하는 즉시 그 라운드의 시안 이미지를 삭제하고, 적용된 지 30일이 지난 라운드의 이미지도 같은 방식(그 가게의 새 시안 요청이 받아들여질 때)으로 삭제합니다. 라운드 기록(행)은 남깁니다.
  • 적용된 그림: 점주가 되돌리기 전까지 가게에 남습니다.
