개인정보처리방침

월계 마스코트는 음식점 탐색·방문 인증·수집품 기능에 필요한 정보만 처리하며, 사용자 개인키나 복구 문구를 요구하거나 저장하지 않습니다.

현재 상태: 이 서비스는 Google Play 일반 공개 전 개발·검증 단계입니다. 실제 일반 공개 전 처리 위탁 계약과 법률 검토 결과를 반영해 이 문서를 갱신합니다. 이 처리방침과 함께 이용약관이 적용됩니다.

1. 처리하는 정보

  • 선택 사진 수집품 제작: 점주가 고른 대표 사진·장면 원본, 편집 좌표·스티커·등급·대사와 선택 음성. 사진 편집은 브라우저에서 하고 초안 저장/게시 때 권한 있는 API·DB에 보관합니다. 서버는 저장할 때 모든 사진에서 촬영 위치·기기 같은 부가 정보(EXIF 등)를 지우고(JPEG의 방향값만 남김), MP3의 곡 정보 태그(ID3·APE)와 브라우저 녹음(Ogg)의 태그를 지우며, 태그·제목 같은 부가 정보가 든 WebM 녹음은 받지 않습니다. 음성 길이는 서버가 파일 안의 정보로 다시 구해 30초를 넘으면 받지 않습니다(MP3는 프레임 수로, Ogg·WebM 녹음은 파일에 적힌 위치·시각 값으로 구하며, 소리를 다시 디코딩해 확인하는 것은 아닙니다). 외부 AI에는 보내지 않으며 고객에게는 보유한 등급의 편집된 이미지·장면과 위와 같이 정리한 음성만 전달합니다. 이 경로는 신규 기능 배포 후 제공됩니다.
  • 서비스 이용: 방문한 점포·캠페인, QR 인증과 보상 처리 상태, 도감 및 계정 삭제 요청 상태(접수·취소·처리 날짜, 접수번호의 해시)
  • 선택적 지갑 연결: 공개 지갑 주소, 요청 체인, nonce, 주소 통제 확인 결과와 연결 버전

  • 친구 기능: 별명, 친구 코드, 친구 관계, 친구를 끊은 기록(다시 추가하지 못하게 하는 차단), 친구 코드 입력 실패 기록
  • 방문·쿠폰 되돌리기 기록: 직원이 잘못 확인한 방문을 취소하거나 쿠폰 사용 처리·발급을 되돌릴 때 남는 상태(취소·무효), 고른 사유(정해진 목록), 선택 메모(100자 이하), 처리한 직원·관리자의 계정 식별자와 처리 시각

  • 가게 그림: 점주가 AI 가게 그림을 요청할 때의 요청 기록(요청자 계정 식별자, 진행 상태, 만들어진 시안·최종 그림)과 가게가 고른 대표 그림

Google 비밀번호, 외부 지갑 비밀번호, 개인키, 복구 문구는 처리하지 않습니다. 서명은 주소 통제 확인에만 사용하며 자산 송금·승인 권한을 요청하지 않습니다.

3. 친구 기능과 친구에게 보이는 정보

친구는 서로 코드를 주고받아 만들며, 코드를 아는 사람만 추가할 수 있습니다. 전체 사용자 검색과 앱 안 메시지는 없습니다.

  • 별명과 친구 코드: 처음 친구 화면을 열면 기본 별명(“탐험가 XXXX”, 코드와 관계없는 무작위 글자)과 헷갈리는 글자(0·O·1·I)를 뺀 8자리 친구 코드가 만들어집니다. 별명은 언제든 바꿀 수 있고, 코드는 언제든 새로 만들 수 있습니다. 새 코드를 만들면 예전 코드로는 더 이상 추가할 수 없고 지금 친구는 그대로입니다.
  • 친구에게 보이는 정보: 별명, 메달 3종의 등급, 배지 수(9개 중), 가본 가게의 이름과 친구 순위만 보입니다. 방문한 날짜·시각·횟수, 쿠폰, 지갑 주소와 NFT, 계정 식별자, 이메일은 친구에게 보이지 않습니다.
  • 하루 늦게 반영: 친구에게 보이는 메달·가게·순위는 한국 날짜 기준 어제까지의 방문만 셉니다. 오늘 다녀온 가게는 다음 0시(한국 시간)부터 보입니다. 다만 친구가 매일 확인하면 새 가게가 어느 날 목록에 생겼는지로 그 가게를 다녀온 날을 짐작할 수 있습니다.
  • 친구 끊기: 친구를 끊으면 양쪽 화면에서 관계와 여권이 사라집니다. 끊은 사람의 계정에는 상대가 이 계정으로 다시 추가하지 못하게 하는 차단 기록이 남습니다. 차단은 계정 기준이라 코드를 새로 만들어도 유지되고, 끊은 사람이 나중에 그 친구를 다시 추가하면 풀립니다. 다만 상대가 다른 계정으로 로그인하면 이 차단은 적용되지 않습니다. 이미 현재 코드를 아는 상대가 다른 계정으로 다시 추가하지 못하게 하려면 코드를 새로 만들어야 하며, 앱은 친구를 끊은 직후 코드 바꾸기를 권합니다.
  • 코드 입력 제한: 코드 입력이 계정당 10분에 10회 실패하면 그 뒤(11번째 시도부터)에는 무차별 대입을 막기 위해 잠시 입력을 제한하며, 이를 위해 실패 시각을 기록합니다.
  • 공유: 친구 코드 공유와 가게 추천은 기기의 공유 화면으로 링크를 내보내며 앱이 직접 메시지를 보내지 않습니다. 친구 코드는 링크의 # 뒷부분에 담겨 브라우저가 서버로 보내지 않으므로 웹 서버 접속 기록과 링크 미리보기에 남지 않습니다. 다만 코드 공유 문구에는 코드가 일반 글자로도 들어 있어, 그 문구를 보내는 메신저 앱과 서비스는 코드를 볼 수 있습니다.

4. 외부 서비스와 공개 장부

운영 과정에서 Google 로그인, Reown 지갑 연결, Base 블록체인, AWS API·DB 호스팅, Vercel 정적 문서 호스팅, OpenAI 이미지 API를 사용합니다. 각 서비스는 자체 정책에 따라 정보를 처리할 수 있습니다.

  • OpenAI(미국): 사장님 AI 가게 그림 생성. 가게 이름·메뉴 이름만 보내고 계정·고객·점주 개인정보는 보내지 않음. user 값으로 가게 id의 해시만 보냄. OpenAI API 기본 정책상 학습에 쓰지 않고 남용 감시 목적으로 최대 30일 보관.

국외 이전(개인정보 보호법 제28조의8): 가게 그림을 만들 때 가게 이름과 메뉴 이름이 미국에 있는 OpenAI 서버로 전송됩니다. 개인사업자의 가게 이름은 사람을 알아볼 수 있는 정보가 될 수 있으므로 국외 이전 정보로 안내합니다.

  • 이전 항목: 가게 이름과 메뉴 이름(최대 5개)입니다. 두 단계 모두 user 값으로 가게 id의 해시만 함께 보내며, 계정·고객·점주 개인정보는 보내지 않습니다.
  • 이전 국가·시기·방법: 미국으로, 점주가 앱에서 아래 버튼을 눌러 요청할 때에만 옮겨집니다. 앱의 요청을 받은 서버가 OpenAI 이미지 API를 호출하는 방식으로 암호화된 연결(HTTPS)을 통해 네트워크로 전송합니다. 요청하지 않으면 아무것도 전송되지 않습니다.
  • 전송이 일어나는 버튼: “AI 시안 받기”와 “새 시안 받기”는 가게 이름과 메뉴 이름으로 시안 네 장을 요청합니다. “이 시안으로 고급 그림 만들기”와 “이 시안으로 고급 그림 다시 만들기”는 점주가 고른 시안 한 장(OpenAI가 만든 그림)과 고정된 안내 문장만 다시 보내며, 이때는 가게 이름과 메뉴 이름을 다시 보내지 않습니다.
  • 받는 자와 연락처: OpenAI(미국)입니다. 개인정보처리자는 OpenAI OpCo, L.L.C.(미국 캘리포니아주 샌프란시스코 3번가 1455번지)이며 문의는 privacy@openai.com으로 합니다. 국내대리인은 오픈에이아이코리아 유한회사(서울특별시 강남구 테헤란로 518, 10층)이며 privacykorea@openai.com 또는 전화 02) 722-3599로 문의할 수 있습니다(OpenAI 한국 이용자 부록 2026-03-27 갱신 기준). 그 밖의 처리 내용은 OpenAI 개인정보 처리방침에서 확인할 수 있습니다.
  • 이용 목적과 보유 기간: 가게 그림 생성이 목적이며, 위 OpenAI 항목대로 학습에 쓰지 않고 남용 감시 목적으로 최대 30일 보관됩니다.
  • 거부 방법과 효과: 위 버튼을 누르지 않으면 이전은 일어나지 않으며 별도 신청은 필요 없습니다. 거부하면 사장님 AI 가게 그림 기능만 쓸 수 없고 음식점 탐색·방문 인증·도감 등 나머지 서비스는 그대로 이용할 수 있습니다.

실제 NFT가 발행되면 지갑 주소, 거래 해시, 계약 주소, token ID가 공개 블록체인에 남습니다. 개인정보·주문번호·정확한 식사 시각은 NFT 메타데이터나 공개 장부에 넣지 않습니다.

NFT 메타데이터는 누구나 읽을 수 있는 공개 주소(https://masscom.kr/nft-metadata/…)에 있으며 가게 이름, 가게의 동네(행정동)·업종, 방문 단계(예: 3번째 방문), 캠페인 이름과 가게 그림을 담습니다(발행 때 공개 중이 아닌 가게는 가게 정보 없이 방문 단계만 담습니다). 메타데이터 자체는 가게에 대한 정보지만, NFT는 받는 사람의 지갑 주소에 묶여 공개 블록체인에 남으므로 그 지갑을 가진 사람이 그 가게를 몇 번째로 방문했는지가 누구에게나 보이게 됩니다. 발행 시각(블록 시각)도 공개 블록체인에 기록됩니다. 메타데이터는 발행이 확정될 때 고정되어 뒤에 가게 정보가 바뀌어도 이미 발행한 NFT는 바뀌지 않고 지울 수 없으므로, 앱은 발행 전에 이 내용을 알리고 동의(판 nft-mint-v2)를 받습니다. 가게 주소, 방문 시각, 주문·결제, 계정 정보는 메타데이터에 넣지 않습니다.

5. 보관과 삭제

삭제 요청과 처리 기한: 웹 삭제 안내 페이지에서 앱에서 쓴 Google 계정으로 로그인해 삭제를 접수하면 접수번호를 한 번 보여 드립니다. 접수·취소·접수번호 다시 받기는 최근 10분 안에 한 로그인이 있어야 하며, 그보다 오래된 로그인이면 다시 로그인하도록 안내합니다. 접수한 뒤 24시간은 취소할 수 있고, 그 뒤 운영자가 확인해 접수 뒤 7일 안에 처리합니다. 처리하면 계정이 사라지므로 접수번호만이 처리 결과를 확인할 수 있는 방법입니다. 처리(또는 취소·거절)하면 접수 기록에서 계정 식별자를 지웁니다. 그 뒤에도 남는 것은 접수번호의 해시, 접수·취소 마감·처리 기한·취소·처리 날짜, 처리 결과, 접수 경로(웹 또는 시연 앱), 처리한 방식(관리자 웹 또는 시연 서버 운영자 이름), 운영자가 처리하지 않기로 할 때 직접 적은 사유이며, 처리·거절한 사실은 감사 기록(요청 번호와 처리한 운영자)으로도 남습니다. 처리 기한 7일은 운영자가 직접 처리해야 지켜지는 약속이라 자동으로 보장되지 않으며, 관리자 목록이 기한을 넘긴 요청을 표시해 확인합니다. 접수번호로 조회하면 기한이 지난 요청에 "처리 기한이 지났어요. 문의해 주세요."가 표시됩니다. 접수번호가 생기기 전에 접수된 요청(접수번호가 없는 요청)은 처리하지 않고, 접수한 분이 다시 접수하면 접수번호와 함께 24시간 취소 기간·7일 처리 기한이 그때부터 새로 시작합니다. 시연 앱은 앱 안에서 같은 방식으로 접수합니다. 처리 결과에 이의가 있으면 문의 이메일로 알려 주세요.

계정 삭제가 완료되면 로그인 세션은 기록째 삭제하고 지갑 연결을 끊고, 미전송 발행 작업을 취소하며 계정 식별자를 비식별 별칭으로 교체합니다. 방문 기록, 쿠폰(이미 사용한 쿠폰 포함), 캠페인 참여 기록, QR 수령 기록, 지갑 연결 주소 기록은 삭제하지 않고 계정 식별자만 비식별 별칭으로 바꿔 남깁니다(발급 수·정원 집계, 사용 감사, 중복 발행 방지와 장부 대조용이며, 지갑 주소 자체는 별칭에 붙어 남습니다). 별명·친구 코드·친구 관계·친구를 끊은 기록(내가 끊은 기록과 나를 끊은 기록 모두)·코드 입력 실패 기록·방문 후 가게 의견(특징 선택·바라는 점·의견)은 같은 처리에서 지워지며 가명 처리로 남기지 않습니다. 제출되었거나 확정된 거래와 NFT 기록은 중복 발행 방지와 공개 장부 대조를 위해 보존될 수 있습니다. 블록체인에 이미 기록된 정보는 서비스가 삭제할 수 없습니다.

방문·쿠폰 되돌리기 기록: 취소한 방문, 무효로 한 쿠폰, 사용을 되돌린 쿠폰은 지우지 않고 상태·사유·처리자·시각을 남깁니다. 되돌린 결과가 보상과 쿠폰 규칙에 맞는지 다시 확인하고 같은 방문이 두 번 세어지지 않게 하려는 것입니다. 사유는 정해진 목록에서 고르고 선택 메모는 100자 이하이며, 메모에 이메일·웹 주소·긴 숫자열(전화번호 등)이 보이면 서버가 거절합니다. 이름·주소 같은 그 밖의 개인정보는 자동으로 걸러내지 못하므로 직원에게 적지 않도록 화면에서 안내합니다. 직원 화면에는 고객의 계정 식별자나 이메일 대신 점포마다 다른 짧은 가림 표시만 보입니다. 처리한 직원·관리자 계정을 삭제하면 이 기록의 처리자 식별자는 같은 처리에서 비식별 별칭으로 바뀌고, 고객 계정을 삭제하면 방문·쿠폰의 고객 식별자가 비식별 별칭으로 바뀝니다. 이 되돌리기 기록 중 별도 감사 기록(쿠폰 사용 되돌리기·재계산 무효·되살리기, 관리자의 쿠폰 무효 처리)은 기록한 날부터 1년 뒤 삭제합니다. 방문·쿠폰 자체에 남는 취소·무효 상태와 사유·처리자·시각은 그 방문·쿠폰과 함께 보관하며, 아래 보관 기간의 계정 삭제 처리를 따릅니다.

사진 제작 자료: 점주는 초안을 지우거나(행째 삭제) 게시한 수집품을 게시 중지·삭제할 수 있습니다. 게시 중지는 그 수집품이 새 방문 고객에게 더 나가지 않게 하고, 게시한 수집품을 삭제하면 게시 중지와 함께 비공개 원본·편집 자료·작성자 계정 연결도 지웁니다. 계정 삭제 때는 해당 계정이 작성·편집에 참여한 프로젝트와 그 복사본의 비공개 원본·편집 자료·계정 연결을 지우고, 그 계정이 만든 게시 수집품은 같은 처리에서 게시를 멈춥니다. 이미 수집품을 받은 고객에게는 받은 당시의 가공 게시 이미지·인사말·선택 음성·장면이 남습니다(보유자 인증이 필요한 상세로만 보이며 공개 미디어 주소·NFT/IPFS로 내보내지 않습니다). 사진에 나온 분이나 목소리의 주인이 삭제를 요청하면 운영자가 확인한 뒤 그 게시 수집품과, 같은 가게에서 그것을 복사해 만든 수집품·초안 및 같은 원본 사진·음성 파일을 쓴 수집품의 이미지·음성·장면을 이미 받은 고객의 도감에서도 지우고(방문·보상 기록은 남습니다) 원본 자료도 지웁니다. 같은 분을 따로 다시 찍어 올린 사진처럼 파일이 다른 수집품은 운영자가 가게의 남은 수집품을 확인해 함께 처리합니다. 이 요청은 문의 이메일로 받습니다. 요청이 없으면 이미 받은 고객의 게시 미디어는 그 보상 기록이 남는 동안 함께 보관하며 별도의 기한을 두지 않습니다.

가게 그림 요청 기록의 요청자 계정 식별자는 계정 삭제 때 비웁니다. 점주가 가게 그림으로 적용한 그림은 가게 자산이므로 삭제하지 않고 가게에 남깁니다.

  • 적용하지 않은 라운드: 만든 지 30일이 지난 라운드는 그 가게의 새 시안 요청이 받아들여질 때 함께 삭제합니다. 정해진 시각에 따로 지우는 작업은 아직 없으므로, 그 가게가 새 시안을 요청하지 않으면 남아 있을 수 있습니다.
  • 적용한 라운드: 적용하는 즉시 그 라운드의 시안 이미지를 삭제하고, 적용된 지 30일이 지난 라운드의 이미지도 같은 방식(그 가게의 새 시안 요청이 받아들여질 때)으로 삭제합니다. 라운드 기록(행)은 남깁니다.
  • 적용된 그림: 점주가 되돌리기 전까지 가게에 남습니다.

보관 기간

  • 계정·방문·보상·친구 기록: 탈퇴(계정 삭제 요청 처리)할 때까지 보관합니다. 처리(접수 뒤 7일 이내) 때 삭제하거나 알아볼 수 없는 값(가명)으로 바꿉니다. 가명으로 바꿔 남기는 기록과 그 이유는 위에 적었습니다.
  • 동의 기록: 계정을 삭제할 때까지 보관하고, 삭제 처리 때 지웁니다(가명으로 남기지 않습니다). 약관·처리방침 버전이 바뀌어 다시 동의하면 이전 버전의 동의 기록도 그때까지 함께 남습니다.
  • 방문 후 가게 의견: 계정을 삭제할 때까지 보관하고, 삭제 처리 때 지웁니다(가명으로 남기지 않습니다). 같은 가게에 다시 고르면 이전 선택을 덮어쓰고, 모두 비우면 바로 지웁니다.
  • 로그인 세션: 만료되거나 로그아웃으로 해지되면 서버의 정리 작업(하루 한 번)이 지웁니다. 앱 로그인의 유효 기간은 30일, 웹 로그인은 24시간입니다. 계정 삭제를 처리할 때는 그 계정의 세션을 바로 지웁니다.
  • 일회용 확인 기록: 방문 수령 때 쓰는 고객 확인 QR의 일회용 값, 지갑 주소 확인 요청, 웹 로그인 진행 상태, 직원 등록 코드는 만료되었거나 사용한 지 1일이 지나면 서버의 정리 작업이 지웁니다. 만료된 값은 어차피 쓸 수 없습니다.
  • 삭제 접수 기록: 처리·취소·거절한 뒤 1년이 지나면 삭제합니다. 처리를 기다리는 접수는 처리될 때까지 보관합니다. 삭제를 처리했다는 원장(계정 식별자의 해시, 비식별 별칭, 처리 결과)은 삭제된 계정이 다시 살아나지 않게 하고 제출된 NFT 발행과 대조하려고 계속 보관합니다.
  • 접근권한 기록: 관리자 권한 부여·회수 기록, 직원 등록 승인·해제 기록, 점주 지정·해제 기록은 기록한 날부터 3년 뒤 삭제합니다(개인정보의 안전성 확보조치 기준 제5조 제3항이 정한 접근권한 부여·변경·말소 기록의 최소 보관 기간).
  • 관리자·점주 처리·감사 기록: 위 접근권한 기록을 뺀 관리자 처리 기록(점포·캠페인·혜택 관리, 쿠폰 무효, 계정 삭제 처리)과 방문·쿠폰 되돌리기 감사 기록은 기록한 날부터 1년 뒤 삭제합니다(개인정보의 안전성 확보조치 기준 제8조의 접속기록 최소 보관 기간에 맞춥니다).
  • 서버 로그: 웹 서버는 요청마다 접속 기록을 남기지 않도록 구성했습니다. API·웹·데이터베이스·웹 서버 컨테이너의 시작·오류 메시지는 용량 기준으로만 순환합니다. 컨테이너마다 10 MB 파일 3개(최대 30 MB)까지 보관하고 넘치면 가장 오래된 것부터 지우며, 시간 기준으로 지우지는 않습니다. 컨테이너를 다시 만들 때(배포 때)는 그 컨테이너의 로그도 함께 사라집니다. 데이터베이스는 오류 로그에 오류가 난 행의 값(상세 항목)과 실패한 SQL 문을 남기지 않도록 설정하며, 이 설정은 배포가 데이터베이스 컨테이너를 다시 만들 때 적용됩니다. 다만 잘못된 입력 형식 같은 일부 오류 문구에는 입력한 값이 들어갈 수 있습니다.
  • 배포 전 데이터베이스 백업: 서버에 만든 지 30일이 지난 백업은 다음 날 정리 작업(하루 한 번) 때 삭제합니다. 백업에는 만든 시점의 계정 데이터가 들어 있어, 계정 삭제를 처리한 뒤에도 그보다 먼저 만든 백업에는 30일이 지날 때까지 남습니다.
  • OpenAI 전송분: OpenAI의 정책을 따릅니다(위 4절: 학습에 쓰지 않고 남용 감시 목적으로 최대 30일).
  • 발행된 NFT: 공개 블록체인에 기록된 정보는 서비스가 지울 수 없습니다.

위 기간은 서버에서 실제로 실행하는 정리 작업(세션·삭제 접수·감사 기록·백업)과 컨테이너 로그 순환 설정에 맞춘 것입니다. 실행하지 않는 기간은 적지 않습니다. 기간이 바뀌면 처리방침 버전을 올리고 다시 동의를 받습니다.

6. 이용자의 선택과 문의

지갑 없이 음식점 탐색·방문 인증·도감을 이용할 수 있고, 친구 기능은 쓰지 않아도 됩니다. 앱의 계정 설정에서 열리는 웹 계정 삭제 안내에서 삭제를 요청할 수 있습니다(24시간 안에는 취소할 수 있고, 처리 기한은 접수 뒤 7일입니다).
