월계 마스코트 앱 열기

운영 테스트 앱이 설치돼 있으면 이 주소가 앱의 음식점 탐색 화면으로 연결됩니다.

앱이 열리지 않나요? Android의 링크 자동 열기 설정이 꺼져 있으면 브라우저에 이 안내가 남을 수 있습니다. 아래 운영 test.6과 최신 시연 Preview 15 APK는 GitHub 로그인 없이 받을 수 있습니다. 시연 앱은 가상 데이터를 사용하며 Google Play 승인본이 아닙니다.

앱을 업데이트해 주세요. 2026-10-01에 개인정보 처리방침 버전이 privacy-2026-10-01로 바뀌었습니다. 새 버전에 아직 동의하지 않은 계정은 이전 설치본인 운영 앱 test.4와 시연 앱 Preview 12·13에서 '앱을 업데이트해 주세요' 안내에 막힙니다. 아래 test.6과 Preview 15로 업데이트하면 동의 화면이 다시 나타나고, 세 가지 필수 항목에 동의해야 시작할 수 있습니다. 새 동의 화면은 이전 운영 설치본 위 설치에서 확인했습니다. test.6과 Preview 15는 이미 동의한 계정으로 설치 뒤 로그인이 이어지는 것까지 확인했습니다.

운영 테스트 앱 · 현재 다운로드 가능

운영 test.6 APK는 실제 운영 API를 사용하는 별도 테스트 설치본입니다. 현재 공개된 실제 음식점은 0곳이며 시연 가상 점포가 들어 있지 않습니다. Google Play 승인본은 아닙니다.

  1. 운영 Android test.6 릴리스에서 APK asset을 내려받습니다.
  2. Release의 SHA256SUMS.txt와 다운로드한 APK의 SHA-256을 비교합니다.
  3. 브라우저의 알 수 없는 앱 설치 권한을 이번 설치에만 허용하고 앱을 실행합니다.

APK 내부 버전은 아직 0.1.0-test.2·versionCode 2이며 test.6은 GitHub 배포 순서입니다. main 4c0c6db(PR #326: 운영 앱 번들에 시연 API 주소가 들어가던 문제 수정, Issue #325)로 만들었고, 빌드 확인으로 운영 API 주소만 들어 있고 시연 API 주소는 없음을 확인했습니다. Samsung 휴대전화에서 test.5 위에 설치해 이미 동의한 계정의 로그인 유지, 탐색(배지 0/9·동네 음식점 0곳)·지도·도감(흰 화면 없음)·상점(0P, 뽑기권 마일리지 부족 안내)·내 정보의 효과음 스위치까지 확인했고 시연 전용 '테스트 방문 만들기'는 보이지 않았습니다. 운영 서버에는 실제 방문·구매를 만들지 않았습니다. 실제 QR·방문·NFT, 지갑 연결, 받은 수집품 화면은 아직 검증하지 않았습니다. 서명·설치 검증 범위를 확인하세요.

시연 앱 · 최신 공개 시험본

이전 시연 Android Preview 3은 같은 계정의 기존 15분 수령 QR 카메라 촬영→수령까지 확인한 공개 APK입니다. 새 시연 API에서는 이 버전의 직원 발급 요청이 호환되지 않으므로 새 방문 시연에는 사용하지 마세요.

최신 시연 Android Preview 15는 공개 GitHub Release에서 받을 수 있습니다. main 4c0c6db(PR #326 포함)로 이전 Preview 위에 만들었고, 빌드 확인으로 APK와 AAB 모두 https://demo-api.masscom.kr만 품고 운영 API 주소는 없음을 확인했으며 녹음 권한(RECORD_AUDIO)은 없습니다. 새 처리방침에 동의하지 않은 계정은 이전 Preview 12·13에서 '앱을 업데이트해 주세요' 안내에 막히므로 최신 Preview로 업데이트하세요. Samsung 휴대전화에서 Preview 14 위에 설치한 뒤 역할 선택→사용자 로그인, 가상 점포 3곳 탐색, 도감과 '외부 지갑 주소 확인' 버튼(이전에 앱이 멈추던 자리), 상점 뽑기(150P→50P), 방문 인증의 '테스트 방문 만들기'(가상 점포 B 도장·배지·상자), 상자 열기 쿠폰(시연용), 딥링크로 보상 상자 열기까지 확인했습니다. 도감으로 이동한 직후 접힘 상태가 풀리지 않고 아래쪽에 머문 현상이 1회 관찰됐으나 재현되지 않았습니다. 시연 서버에 #322 시드가 아직 배포되지 않아 '받은 수집품 보기'(봉투)는 아직 볼 수 없습니다. 실제 QR·방문·NFT, 지갑 연결, TalkBack·다크 모드·글자 200%는 아직 검증하지 않았습니다(미검증). 시연 앱은 친구 코드 문구와 https://masscom.kr/open 안내를 공유하고 QR은 시연 앱 전용 주소를 씁니다. 운영 앱과 package·API·데이터가 다르며, 가상 점포 A/B/C는 실제 영업점·방문 혜택이 아닙니다. 설치하지 않고 보려면 읽기 전용 시연 웹을 여세요. 검증 범위를 확인하세요.

안전 경계

이 테스트 앱은 Google Play 승인본이 아닙니다. 외부 지갑 비밀번호, 개인키, 복구 문구를 입력하지 마세요. 앱은 주소 확인용 서명만 요청하며 송금·승인·스왑·구매를 요청하지 않습니다.
