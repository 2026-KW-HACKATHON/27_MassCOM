앱이 열리지 않나요? Android의 링크 자동 열기 설정이 꺼져 있으면 브라우저에 이 안내가 남을 수 있습니다. 아래 운영 test.10와 최신 시연 Preview 19 APK는 GitHub 로그인 없이 받을 수 있습니다. 시연 앱은 가상 데이터를 사용하며 Google Play 승인본이 아닙니다.

앱을 업데이트해 주세요. 개인정보 처리방침이 바뀌었으므로 이전 설치본은 아래 운영 test.10 또는 시연 Preview 19로 업데이트해야 합니다. 세 가지 필수 항목에 동의해야 시작할 수 있습니다. 운영 test.10 로그인은 NOT_RUN이고 시연 Preview 19는 동의 화면 표시와 동의 거절 뒤 로그아웃까지 확인했습니다.

운영 테스트 앱 · 현재 다운로드 가능

운영 test.10 APK는 실제 운영 API를 사용하는 별도 테스트 설치본입니다. 현재 공개된 실제 음식점은 0곳이며 시연 가상 점포가 들어 있지 않습니다. Google Play 승인본은 아닙니다.

  1. 운영 Android test.10 릴리스에서 APK asset을 내려받습니다.
  2. Release의 SHA256SUMS.txt와 다운로드한 APK의 SHA-256을 비교합니다.
  3. 브라우저의 알 수 없는 앱 설치 권한을 이번 설치에만 허용하고 앱을 실행합니다.

APK 내부 버전은 아직 0.1.0-test.2·versionCode 2이며 test.10은 GitHub 배포 순서입니다. main db28003으로 만들었고 업로드 인증서·익명 다운로드 뒤 APK SHA-256 재대조·릴리스 지갑 표면을 확인했습니다. 녹음 권한(RECORD_AUDIO)은 없습니다. 연결된 휴대전화가 없어 이번 APK의 실제 설치·실행·로그인·지갑·실제 QR·Google Play는 NOT_RUN입니다. 운영 공개 점포는 0곳이며 운영 API에는 읽기 전용 GET만 사용했습니다. 서명·설치 검증 범위를 확인하세요.

시연 앱 · 최신 공개 시험본

이전 시연 Android Preview 3은 같은 계정의 기존 15분 수령 QR 카메라 촬영→수령까지 확인한 공개 APK입니다. 새 시연 API에서는 이 버전의 직원 발급 요청이 호환되지 않으므로 새 방문 시연에는 사용하지 마세요.

최신 시연 Android Preview 19은 공개 GitHub Release에서 받을 수 있습니다. main db28003으로 만들었고 APK와 AAB 모두 https://demo-api.masscom.kr만 품고 운영 API 주소는 없음을 확인했습니다. 이제 로그인 없이 바로 체험을 제공합니다. Android 에뮬레이터(720×1280, 글꼴 100%)에서 이전 Preview 위 설치, Google 로그인과 체험 버튼·설명 표시, 임시 체험 시작, 사용자 선택 뒤 필수 체크 세 개가 있는 동의 화면, 동의하지 않고 로그아웃한 뒤 정상 첫 화면 복귀를 확인했습니다. 공개 서버에서 동의를 수락하지 않았으므로 홈·테스트 방문·가상 점포 C 프리즘·체험 처음부터 다시·체험 점포 점주 화면은 NOT_RUN입니다. 실제 휴대전화·실제 QR·지갑·TalkBack·글자 200%도 NOT_RUN입니다. 운영 앱과 package·API·데이터가 다르며 가상 점포 A/B/C는 실제 영업점·방문 혜택이 아닙니다. 설치하지 않고 보려면 읽기 전용 시연 웹을 여세요. 검증 범위를 확인하세요.

안전 경계

이 테스트 앱은 Google Play 승인본이 아닙니다. 외부 지갑 비밀번호, 개인키, 복구 문구를 입력하지 마세요. 앱은 주소 확인용 서명만 요청하며 송금·승인·스왑·구매를 요청하지 않습니다.
