월계 마스코트 앱 열기

운영 테스트 앱이 설치돼 있으면 이 주소가 앱의 음식점 탐색 화면으로 연결됩니다.

앱이 열리지 않나요? Android의 링크 자동 열기 설정이 꺼져 있으면 브라우저에 이 안내가 남을 수 있습니다. 아래 운영 test.3과 최신 시연 Preview 12 APK는 GitHub 로그인 없이 받을 수 있습니다. 시연 앱은 가상 데이터를 사용하며 Google Play 승인본이 아닙니다.

운영 테스트 앱 · 현재 다운로드 가능

운영 test.3 APK는 실제 운영 API를 사용하는 별도 테스트 설치본입니다. 현재 공개된 실제 음식점은 0곳이며 시연 가상 점포가 들어 있지 않습니다. Google Play 승인본은 아닙니다.

  1. 운영 Android test.3 릴리스에서 APK asset을 내려받습니다.
  2. Release의 SHA256SUMS.txt와 다운로드한 APK의 SHA-256을 비교합니다.
  3. 브라우저의 알 수 없는 앱 설치 권한을 이번 설치에만 허용하고 앱을 실행합니다.

APK 내부 버전은 아직 0.1.0-test.2·versionCode 2이며 test.3은 GitHub 배포 순서입니다. 서명·설치·로그인 검증 범위를 확인하세요.

시연 앱 · 최신 공개 시험본

이전 시연 Android Preview 3은 같은 계정의 기존 15분 수령 QR 카메라 촬영→수령까지 확인한 공개 APK입니다. 새 시연 API에서는 이 버전의 직원 발급 요청이 호환되지 않으므로 새 방문 시연에는 사용하지 마세요.

최신 시연 Android Preview 12는 공개 GitHub Release에서 받을 수 있습니다. 로그인하면 메인 화면보다 먼저 전체 화면 동의 화면이 나타나 필수 세 가지(만 14세 이상, 이용약관, 개인정보 수집·이용)에 모두 동의해야 시작할 수 있고, 이용약관·개인정보 처리방침·계정 삭제 안내 링크가 내 정보에 더해졌습니다. 점원·점주 화면의 방문 취소·쿠폰 사용 되돌리기와 접수번호를 받는 '계정 삭제 요청'은 Preview 11과 같습니다. 점주 화면의 '가게 그림 만들기'는 서버에 API 키가 들어가기 전까지 꺼져 있고 '준비 중'으로 보입니다. APK 서명·원격 해시와 Samsung 휴대전화의 기존 앱 위 설치·첫 실행·동의 화면(세 개 중 두 개만 체크하면 '동의하고 시작'이 꺼져 있고 세 개를 모두 체크하면 켜지며 제출하면 가상 점포 3곳의 탐색 목록으로 넘어감)·이용약관 보기 링크의 브라우저 열기·내 정보의 링크 세 개까지 확인했습니다. 알려진 결함: 세 개를 모두 체크하면 켜진 버튼의 글자가 '동의하고'까지만 보이고 '시작'이 잘리지만 동작은 정상이며 다음 빌드에서 고칠 예정입니다. 지갑을 연결해야 나오는 발행 동의(v2) 대화상자, 동의를 거절하고 로그아웃하는 경로, 앱 안 약관 링크가 여는 페이지의 내용, TalkBack·다크 모드·글자 200%, 실제 점원의 방문 취소와 쿠폰 되돌리기, 실제 AI 그림 생성과 고객 화면의 AI 그림 표시, 두 시연 계정 사이의 친구 추가, 시연 앱의 링크 열기, 시스템 공유창, 로그인 뒤 메달·보상 상자·쿠폰 흐름과 새 2분 고객 식별 QR 촬영·두 기기 수령은 아직 검증하지 않았습니다. 시연 앱은 친구 코드 문구와 https://masscom.kr/open 안내를 공유하고 QR은 시연 앱 전용 주소를 씁니다. 운영 앱과 package·API·데이터가 다르며, 가상 점포 A/B/C는 실제 영업점·방문 혜택이 아닙니다. 설치하지 않고 보려면 읽기 전용 시연 웹을 여세요.

안전 경계

이 테스트 앱은 Google Play 승인본이 아닙니다. 외부 지갑 비밀번호, 개인키, 복구 문구를 입력하지 마세요. 앱은 주소 확인용 서명만 요청하며 송금·승인·스왑·구매를 요청하지 않습니다.
