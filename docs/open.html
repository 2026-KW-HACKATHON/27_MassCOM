월계 마스코트 앱 열기

운영 테스트 앱이 설치돼 있으면 이 주소가 앱의 음식점 탐색 화면으로 연결됩니다.

앱이 열리지 않나요? Android의 링크 자동 열기 설정이 꺼져 있으면 브라우저에 이 안내가 남을 수 있습니다. 아래 운영 test.5와 최신 시연 Preview 14 APK는 GitHub 로그인 없이 받을 수 있습니다. 시연 앱은 가상 데이터를 사용하며 Google Play 승인본이 아닙니다.

앱을 업데이트해 주세요. 2026-10-01에 개인정보 처리방침 버전이 privacy-2026-10-01로 바뀌었습니다. 새 버전에 아직 동의하지 않은 계정은 이전 설치본인 운영 앱 test.4와 시연 앱 Preview 12·13에서 '앱을 업데이트해 주세요' 안내에 막힙니다. 아래 test.5와 Preview 14로 업데이트하면 동의 화면이 다시 나타나고, 세 가지 필수 항목에 동의해야 시작할 수 있습니다. 새 동의 화면은 운영 test.5에서 확인했고, 시연 Preview 14에서는 동의 화면을 직접 열어 보지 않았습니다.

운영 테스트 앱 · 현재 다운로드 가능

운영 test.5 APK는 실제 운영 API를 사용하는 별도 테스트 설치본입니다. 현재 공개된 실제 음식점은 0곳이며 시연 가상 점포가 들어 있지 않습니다. Google Play 승인본은 아닙니다.

  1. 운영 Android test.5 릴리스에서 APK asset을 내려받습니다.
  2. Release의 SHA256SUMS.txt와 다운로드한 APK의 SHA-256을 비교합니다.
  3. 브라우저의 알 수 없는 앱 설치 권한을 이번 설치에만 허용하고 앱을 실행합니다.

APK 내부 버전은 아직 0.1.0-test.2·versionCode 2이며 test.5는 GitHub 배포 순서입니다. main 7bcfef9(사진 수집품 제작기 PR #257 포함)로 만들었습니다. Samsung 휴대전화에서 test.4 위에 설치하면 새 버전(privacy-2026-10-01)의 동의 화면이 '필수'로 나타나고(앱 업데이트 안내가 아님), 세 항목을 모두 체크하면 '동의하고 시작' 버튼 글자가 전부 보이는 것을 확인했습니다. 실제 계정이라 동의는 제출하지 않았고 제출한 뒤의 흐름, 사진 수집품 수령·재생, 지갑 연결, 실제 QR·방문·NFT는 아직 검증하지 않았습니다. 서명·설치·동의 화면 검증 범위를 확인하세요.

시연 앱 · 최신 공개 시험본

이전 시연 Android Preview 3은 같은 계정의 기존 15분 수령 QR 카메라 촬영→수령까지 확인한 공개 APK입니다. 새 시연 API에서는 이 버전의 직원 발급 요청이 호환되지 않으므로 새 방문 시연에는 사용하지 마세요.

최신 시연 Android Preview 14는 공개 GitHub Release에서 받을 수 있습니다. main 7bcfef9(사진 수집품 제작기 PR #257 포함)로 이전 Preview 위에 만들었습니다. 새 처리방침에 동의하지 않은 계정은 이전 Preview 12·13에서 '앱을 업데이트해 주세요' 안내에 막히므로 Preview 14로 업데이트하세요. 로그인하면 메인 화면보다 먼저 전체 화면 동의 화면이 나타나 필수 세 가지(만 14세 이상, 이용약관, 개인정보 수집·이용)에 모두 동의해야 시작할 수 있고, 이용약관·개인정보 처리방침·계정 삭제 안내 링크가 내 정보에 있습니다. 점원·점주 화면의 방문 취소·쿠폰 사용 되돌리기와 접수번호를 받는 '계정 삭제 요청'도 들어 있습니다. 점주 화면의 '가게 그림 만들기'는 서버에 API 키가 들어가기 전까지 꺼져 있고 '준비 중'으로 보일 것이나 배포 뒤 다시 확인하지 않았습니다. 이번 빌드는 앱 번들에 시연 API 주소만 들어 있는지 검사하는 빌드 확인(Issue #273)을 처음 실제로 거쳐 APK와 AAB 모두 https://demo-api.masscom.kr만 품고 운영 API 주소는 없음을 확인했고, 녹음 권한(RECORD_AUDIO)은 없습니다. Samsung 휴대전화의 기존 앱(Preview 13) 위 설치와 로그아웃 상태 탐색 화면의 가상 점포 3곳까지 확인했습니다. Preview 13을 만들기 전에 같은 소스로 먼저 만든 후보 APK는 운영 API 주소가 들어가 게시하지 않았고 그 탓에 시연 앱 로그인이 풀렸으므로, 시연 앱에 로그인해 두었다면 다시 로그인해야 합니다. 이 APK에서 로그인 뒤 흐름(동의·수집·방문), 사진 수집품의 기기 수령·재생, 지갑을 연결해야 나오는 발행 동의(v2) 대화상자, 실제 QR·방문·NFT, TalkBack·다크 모드·글자 200%, 실제 AI 그림 생성은 아직 검증하지 않았습니다(미검증). 시연 앱은 친구 코드 문구와 https://masscom.kr/open 안내를 공유하고 QR은 시연 앱 전용 주소를 씁니다. 운영 앱과 package·API·데이터가 다르며, 가상 점포 A/B/C는 실제 영업점·방문 혜택이 아닙니다. 설치하지 않고 보려면 읽기 전용 시연 웹을 여세요. 검증 범위를 확인하세요.

안전 경계

이 테스트 앱은 Google Play 승인본이 아닙니다. 외부 지갑 비밀번호, 개인키, 복구 문구를 입력하지 마세요. 앱은 주소 확인용 서명만 요청하며 송금·승인·스왑·구매를 요청하지 않습니다.
