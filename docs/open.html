앱이 열리지 않나요? Android의 링크 자동 열기 설정이 꺼져 있으면 브라우저에 이 안내가 남을 수 있습니다. 아래 운영 test.12와 최신 시연 Preview 21 APK는 GitHub Release에 게시되어 있습니다. 시연 앱은 가상 데이터를 사용하며 Google Play 승인본이 아닙니다.

앱을 업데이트해 주세요. 개인정보 처리방침 privacy-2026-10-07에 맞게 운영 test.12 또는 시연 Preview 21으로 업데이트해 주세요. 세 가지 필수 항목에 동의해야 시작할 수 있습니다. 이번 두 설치본의 실제 설치·실행·로그인은 NOT_RUN입니다.

운영 테스트 앱 · 현재 다운로드 가능

운영 test.12 APK는 실제 운영 API를 사용하는 별도 테스트 설치본입니다. 현재 공개된 실제 음식점은 0곳이며 시연 가상 점포가 들어 있지 않습니다. Google Play 승인본은 아닙니다.

  1. 운영 Android test.12 릴리스에서 APK asset을 내려받습니다.
  2. Release의 SHA256SUMS.txt와 다운로드한 APK의 SHA-256을 비교합니다.
  3. 브라우저의 알 수 없는 앱 설치 권한을 이번 설치에만 허용하고 앱을 실행합니다.

APK 내부 버전은 아직 0.1.0-test.2·versionCode 2이며 test.12은 GitHub 배포 순서입니다. 소스 9f5ebfa으로 만들었고 업로드 인증서·릴리스 지갑 표면을 확인했습니다. 녹음 권한(RECORD_AUDIO)은 없습니다. 이번 APK의 실제 설치·실행·로그인·지갑·실제 QR·Google Play는 NOT_RUN입니다. 운영 공개 점포는 0곳이며 운영 서버의 공개 확인 결과는 별도 배포 증거로 기록합니다. 서명·설치 검증 범위를 확인하세요.

운영 APK MassCOM-operating-android-9f5ebfa.apk는 약 324MB이며 SHA-256은 266c64795ace1e1bbf0ba2bac4224e3638d88a9e6a1633e343ed309a9f4febd3입니다. test.10(약 163MB)보다 커진 이유는 지도 SDK 네이티브 라이브러리(navermap·TMAP vsmsdk) 4개 ABI입니다.

시연 앱 · 최신 공개 시험본

이전 시연 Android Preview 3은 같은 계정의 기존 15분 수령 QR 카메라 촬영→수령까지 확인한 공개 APK입니다. 새 시연 API에서는 이 버전의 직원 발급 요청이 호환되지 않으므로 새 방문 시연에는 사용하지 마세요.

최신 시연 Android Preview 21은 공개 GitHub Release에서 받을 수 있습니다. 소스 9f5ebfa, package kr.masscom.wolgye.demo이며 APK에는 https://demo-api.masscom.kr만 내장되어 있습니다. 시연 키 인증서 일치와 녹음 권한(RECORD_AUDIO)이 없음을 확인했습니다. APK MassCOM-showcase-android-9f5ebfa.apk는 약 330MB이며 SHA-256은 f8c484a60e06084d64e7fe913091ec3901b53c1ce715e932fb9af0b78a807cc4입니다. 이번 설치본의 실제 휴대전화·에뮬레이터·로그인·방문·QR·지갑·TalkBack·글자 200%는 NOT_RUN입니다. 가상 점포 A/B/C는 실제 영업점·방문 혜택이 아닙니다. 설치하지 않고 보려면 읽기 전용 시연 웹을 여세요. 검증 범위를 확인하세요.

시연 서버·설치본에는 TMAP/NAVER 지도 키가 없어 목록 기반 탐색으로 동작합니다.

안전 경계

이 테스트 앱은 Google Play 승인본이 아닙니다. 외부 지갑 비밀번호, 개인키, 복구 문구를 입력하지 마세요. 앱은 주소 확인용 서명만 요청하며 송금·승인·스왑·구매를 요청하지 않습니다.
