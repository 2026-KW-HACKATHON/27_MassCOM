월계 마스코트 앱 열기

운영 테스트 앱이 설치돼 있으면 이 주소가 앱의 음식점 탐색 화면으로 연결됩니다.

앱이 열리지 않나요? 현재 APK는 private GitHub 저장소의 접근 권한이 있는 사용자만 내려받을 수 있습니다.

테스트 APK 설치

  1. Android 휴대전화에서 GitHub 접근 권한이 있는 계정으로 로그인합니다.
  2. MassCOM Android 0.1.0 테스트 2의 APK asset을 내려받습니다.
  3. 브라우저의 알 수 없는 앱 설치 권한을 이번 설치에만 허용하고 앱을 실행합니다.

안전 경계

이 테스트 앱은 Google Play 승인본이 아닙니다. 외부 지갑 비밀번호, 개인키, 복구 문구를 입력하지 마세요. 앱은 주소 확인용 서명만 요청하며 송금·승인·스왑·구매를 요청하지 않습니다.
