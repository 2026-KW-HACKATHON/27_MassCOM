# 탐험 여권: 메달·보상 상자·쿠폰

[Issue #216](https://github.com/2026-KW-HACKATHON/27_MassCOM/issues/216)은 UI/UX 피드백("수집 게임 같은 재미, 더 감성적으로, 공유, 배지를 모으면 쿠폰")을 반영해 [Issue #212](https://github.com/2026-KW-HACKATHON/27_MassCOM/issues/212)의 텍스트 배지 3단계를 **서버가 계산하는 메달·보상 상자·쿠폰**으로 바꿨습니다. 다른 게임의 캐릭터·화면·상표는 쓰지 않고 승인된 월계 마스코트(D-036)와 코드로 그린 SVG만 사용합니다. 상세 계약은 [설계 명세](superpowers/specs/2026-09-29-explorer-passport-design.md)에 있습니다.

## 순환

방문 인증 → 도장 쾅 축하 → 메달 등급 상승 → 배지 3·6·9개마다 보상 상자 → 상자 열기 → 쿠폰 → 매장에서 식별 QR로 사용 → 다음 가게 탐험. 획득한 메달은 이미지 카드로 공유합니다.

## 메달

본인의 유효(`VALID`)·진행 반영 방문만 셉니다. 진행 반영은 (계정, 점포, 한국 날짜)당 한 번이라 같은 날 반복 방문은 늘지 않습니다.

| 메달 | 값 | 브론즈 · 실버 · 골드 |
| --- | --- | --- |
| 동네 탐험가 | 서로 다른 가게 수 | 1 · 2 · 3곳 |
| 단골손님 | 한 가게 최다 방문일 | 2 · 3 · 5번 |
| 꾸준한 걸음 | 방문한 날 수 | 2 · 4 · 7일 |

세 메달의 등급 합(0~9)이 모은 배지 수입니다. 기존 점포별 1·3·5회 앱 수집품과 NFT 규칙(D-006)은 바뀌지 않습니다.

## 보상 상자와 쿠폰

| 상자 | 필요 배지 | 시연 DB 체험 혜택 |
| --- | --- | --- |
| 첫 번째 상자 | 3 | 체험 점주 가게 체험 음료 1잔 |
| 두 번째 상자 | 6 | 체험 점주 가게 체험 디저트 한 접시 |
| 황금 상자 | 9 | 체험 점주 가게 체험 세트 20% 할인 |

- 쿠폰은 **점주 동의 기록이 있는 혜택(offer)** 이 등록된 상자에서만 서버가 발급합니다. 계정·상자당 1장이고, 같은 요청을 다시 보내면 기존 쿠폰을 돌려줍니다. 상자를 열 때 서버가 메달을 다시 계산하므로 앱 표시만으로 쿠폰을 받을 수 없습니다.
- 혜택이 없으면 상자는 "혜택 준비 중"으로 표시되고 쿠폰을 만들지 않습니다. 운영 DB에는 가상 혜택을 넣지 않으며 현재 운영 혜택은 0건입니다(D-043).
- 쿠폰 사용: 고객이 "매장에서 사용하기"를 누르면 기존 2분 식별 QR이 열립니다. 점원이 QR을 촬영하면 **그 점포에서 쓸 수 있는 그 고객의 쿠폰만** 보이고, 확인 뒤 사용 처리합니다. 다른 점포·다른 고객·만료·이미 사용한 쿠폰은 서버가 거절하거나 기존 결과를 돌려줍니다. 쿠폰 사용은 식별 QR을 소모하지 않으므로 쿠폰을 먼저 처리한 뒤 같은 QR로 방문 코드를 발급할 수 있습니다(방문 코드 발급은 QR을 소모). 또 점원에게 원시 계정 ID를 보내지 않습니다.
- 계정 삭제 시 쿠폰의 고객·처리 점원 계정 열을 기존 가명 처리와 함께 끊습니다.

## 운영 혜택 등록 절차

운영 점주 혜택 등록 화면은 이번 범위 밖입니다. 점주와 **혜택 내용, 비용 부담, 유효 기간, 발급 상한, 계정당 1회 사용**을 서면으로 합의한 뒤에만 운영 DB 관리자가 한 건씩 등록합니다. `consent_note`에는 합의 문서의 위치나 식별자를 남기고 개인정보는 넣지 않습니다.

```sql
INSERT INTO badge_reward_offers
  (id, milestone, merchant_id, title, detail, valid_days, issuance_cap, status, consent_note)
VALUES
  ('<uuid>', 1, '<운영 점포 ID>', '<40자 이하 혜택>', '<120자 이하 조건>', 30, 100, 'ACTIVE', '<합의 문서 식별자>');
```

같은 상자에는 `ACTIVE` 혜택이 하나만 있을 수 있습니다. 중단은 `status='PAUSED'`로 바꾸며 이미 발급된 쿠폰은 유효 기간까지 사용할 수 있습니다.

## 공유

획득한 메달은 하늘색 카드(마스코트·메달·등급·"서로 다른 가게 3곳을 발견했어요"·서비스 주소)로 이미지 공유합니다. 계정 ID·방문 날짜·점포 목록·지갑 주소·QR은 넣지 않고, 시연 앱 카드에는 "체험용 가상 기록"을 표시합니다. 이미지 공유가 불가능하면 같은 내용의 글자로 공유합니다. Android는 공유창 취소와 전송 완료를 구분할 수 없어 완료 메시지를 표시하지 않습니다([React Native Share](https://reactnative.dev/docs/share)).

## 연출과 접근성

방문 인증 직후 도장 낙하·잉크 번짐·색종이·햅틱으로 새 등급과 열 수 있는 상자를 알립니다. 감소된 동작 설정에서는 움직임 없이 같은 정보를 보여줍니다([W3C 접근성 지침](https://www.w3.org/WAI/WCAG22/Techniques/css/C39)). 메달·상자·쿠폰 상태는 색만이 아니라 등급 이름과 상태 문구로 전달하고, 큰 글씨에서는 세로로 쌓습니다.
