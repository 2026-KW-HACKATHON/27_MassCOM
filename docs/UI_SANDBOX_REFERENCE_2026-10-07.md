## 읽은 증거

검증 JSON에는 데스크톱67개와 모바일390px67개 상태가 각각 있다. 깨진 이미지0, 데스크톱 overflow 및 모바일 content/document overflow 없음으로 기록돼 있다. 흐름15항목은 일반 뽑기 기존 코인 유지, 리롤 회수/권 차감, NFT 고지·대기/완료 잠금과 다른 미발급 코인 허용, 구매1,280−600=680, 테마, 비친구 방/친구 추가, 소개, 가구 회전/포인터 드래그, 새로고침 유지, 놀이30P를 true로 기록한다.

이는 **독립 HTML/CSS/JS 시제품에서 이전에 실행해 전달된 증거**다. 이 세션이 그 브라우저 시험을 다시 수행한 것은 아니다. 현재 저장소의 Expo 앱 자동 시험·브라우저/Android 검증과 합산하지 않는다. 현재 Expo 검증 상태는 [별도 기록](UI_LOCAL_PREVIEW_2026-10-07.md)을 따른다.

## 후속 작업에 적용할 점

- 원본 비교/겹쳐보기 방식과 모바일 가로 넘침·이미지 누락·콘솔 오류 확인을 Expo 시각 검증 체크리스트로 사용한다.
- 홈 중앙 정렬·보유 권 캐러셀·방문 진행·친구/인증, 가게 중심 이웃 연결과 비친구 방문, 드래그/저장 전후 피드백을 조작 참고로 삼는다.
- 최종 디자인 정본은 원본 시안·최신 사용자 결정이다. 독립 시제품의 스타일/샘플 결과가 이를 덮어쓰지 않는다.
- 사용자에게 명시된 대로 **픽셀 단위 동일 구현은 미달**이다. 글꼴·간격·아이콘·카드 비율을 후속 비교한다. 독립 시제품에도 완전 일치 판정을 붙이지 않는다.
- 2D 배경+가구 오버레이는 3D 엔진이 아니다. 실제 인증·지도/카메라·메시지·결제·지갑/NFT/재고/확률과 연결되지 않은 로컬 시연이다. 운영 기능 완료·보상 정책 승인으로 전환하지 않는다.
