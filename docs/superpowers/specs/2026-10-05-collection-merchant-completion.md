# 수집·게임 경험과 점주 운영 완성

사용자 제공 요청의 1–14절 전체가 범위다. 최신 원격 main `aae64d88973caea2f5ee1b1f13a44173e96e55bb`에서 시작하며 #364의 수집·공간·네 게임 구현과 #365의 점주 정보·관리자 연장 감사를 재사용한다. 이미 있는 기능의 재구현으로 범위를 대체하지 않는다.

## 구현 구조

- 방문 보상, 기존 마일리지 가격, 미보유 캐릭터 보장, 쿠폰 권리는 유지한다. 실제 캐릭터 뽑기 이력에서 꾸미기 보너스를 멱등으로 연결하고 팩의 보상/진행/활용을 함께 안내한다.
- 배지와 네 게임의 서버 재계산 성취로 모자·가방·소품·포즈·장식을 해금한다. 장착 배지·대표 코인·꾸미기·원하는 목표는 서버에 저장한다. 방문 취소로 조건이 사라지면 실제 전시 시 다시 검사한다.
- 홈, 프로필, 내 공간, 친구 공간, 공유는 동일한 장착 상태를 사용한다. 친구의 소장품에서 가게와 획득 목표로 이동한다.
- 네 게임에 각기 다른 실력 목표, 보상 미리보기, 결과/최고기록/재도전을 연결한다. 게임은 방문 마일리지나 쿠폰을 발급하지 않는다.
- 기존 금속/센서 렌더링과 점주 제작기를 다듬는다. 전경·모션 감소·드래그·기울임을 존중하고 옛 작품을 표시한다.
- PNG와 실제 재생 가능한 짧은 영상을 피드/스토리 크기로 생성하고 저장/공유한다. Android는 네이티브 인코더, 웹은 브라우저 인코더를 사용한다. 파일 생성 성공과 외부 게시 성공을 구분한다.
- 알림함/종류별 설정/토큰 수명/로그아웃·계정전환/딥링크/멱등 발송·재시도를 연결한다. FCM 인증 정보가 없어도 알림함·enqueue·mock 발송 검증을 완료한다. 실제 단말 수신은 별도로 확인한다.
- 점주는 자기 가게의 일반 캠페인을 동의·현재 종료일·제한을 확인하고 직접 연장한다. OWNER만 직원 인증 코드 승인·업무 권한 변경·해제를 처리한다. 현재 멤버십과 업무 권한은 각 실제 작업 트랜잭션에서 재검사한다.
- 방문 CSV는 화면과 같은 인정 방문 기준, KST 날짜, 제한 기간, 한글 BOM, 수식 방어를 사용하며 필요한 가명 정보만 포함한다.
- 계정 삭제·권한 변경·취소·재시도·기존 데이터 호환을 검증한다. 운영/시연 데이터와 앱 variant를 격리한다.

## 검증과 종료 조건

기존 기능과 신규 연결에 단위/HTTP/실제 PostgreSQL 회귀 시험을 수행하고 타입/lint/build/site 검사를 실행한다. 로컬 웹에서 방문→획득→장착→네 게임→공간→친구/공유와 점주 연장·직원·CSV를 확인한다. Android 에뮬레이터에서 최신 빌드·영상 파일 재생을 확인한다. 물리 기울임·실제 FCM 수신·운영 배포는 가능한 환경 여부에 따라 별도로 기록한다. 외부 키/계정 설정 부족으로 실행 불가인 항목은 코드 미구현과 구분하여 정확한 조치를 남긴다.

설계·일반 라이브러리 추가·검증·커밋·push·PR·필수 검사 뒤 통합은 사용자 요청에 의해 승인됐다. 유료 서비스, 운영 키 생성, 공개 출시·스토어 제출은 이번 로컬 구현의 완료로 주장하지 않는다.
