# 동네 그림 지도와 길찾기 (Issue #228, D-046)

2026-09-29 소유자 요청: "찾아가는 지도 기능". 소유자는 **앱 안 일러스트 동네 지도 + 네이버·카카오맵 길찾기**를 골랐다(D-046, API 키·비용 없음). 하늘 동네 개편(#224)의 조각(`SkyArt`, `FloatingCard`, `Mascot`, 떠 있는 탭 바)을 그대로 쓴다.

## 1. 목표와 성공 기준

- 탐색 목록과 별개로, 동네를 그림 지도로 한눈에 보고 "어디부터 가 볼까"를 고를 수 있다.
- 지도 위 가게 핀은 방문한 곳(도장)과 아직 안 간 곳이 한눈에 구분된다(색만이 아니라 모양·글자로).
- 핀을 누르면 가게 카드가 올라오고 `자세히 보기`와 `길찾기`를 할 수 있다.
- `길찾기`는 네이버 지도·카카오맵 앱(없으면 웹)을 **도로명 주소 검색**으로 연다. 앱은 위치 권한을 요청하지 않는다.
- 그림 지도는 실제 축척·방향이 아님을 화면에 한 번 밝힌다. 가상 점포는 길찾기를 막고 이유를 보인다.

## 2. 화면 구조

- **탭:** 떠 있는 탭 바에 `지도`를 더한다. 이번 단계는 `탐색 · 지도 · (방문 인증) · 도감` 네 칸이다. 친구(D-047)가 들어오면 `탐색 · 지도 · (방문 인증) · 도감 · 친구` 다섯 칸으로 가운데가 맞는다. 네 칸일 때 가운데 도장 버튼은 세 번째 칸에 둔다.
- **지도 화면(`src/app/(tabs)/map.tsx` → `src/screens/town-map/`):**
  - `AppHeader` "동네 지도" / "그림 지도 · 실제 위치·거리와 달라요".
  - 그 아래 `town-map.png`(세로 1024×1536)를 화면 폭에 맞춰 세로 스크롤로 보인다. 확대·축소는 이번 범위 밖이다.
  - 핀: 지름 44dp 원형 표식(시연 점포 그림 썸네일 또는 `stampGlyph`). 방문한 곳은 도장 잉크 이중 테두리와 작은 체크 배지, 안 간 곳은 점선 테두리. 모두 `accessibilityLabel`에 "가게 이름, 도장 받음/아직 없음".
  - 핀을 누르면 아래에서 `FloatingCard` 시트가 올라온다: 이름·도로명 주소·도장 상태·다음 목표, 버튼 `자세히 보기`(음식점 상세), `길찾기`.
  - 목록이 비었으면 `StateScene`(sleep) "아직 지도에 올릴 가게가 없어요".
- **탐색 화면:** 머리글 아래 칩 옆에 `지도로 보기` 작은 버튼을 둔다(지도 탭으로 이동).

## 3. 핀 위치

그림 지도는 실제 좌표가 없다. `town-map.png`의 가게 건물 8곳에 해당하는 **고정 자리 목록**(그림 좌표 비율 x, y)을 `src/screens/town-map/anchors.ts`에 둔다.
- 가게 ID를 결정적 해시로 자리 번호에 배정한다(같은 가게는 항상 같은 자리). 충돌하면 다음 빈 자리.
- 가게가 8곳보다 많으면 9번째부터는 지도 아래 "지도에 다 담지 못한 가게" 목록 카드로 보인다(YAGNI: 클러스터·확대 없음).
- 시연 점포 A·B·C는 서로 떨어진 자리에 고정 배정해 시연 화면이 항상 같다.

## 4. 길찾기

- 누르면 선택 시트: `네이버 지도`, `카카오맵`, `취소`.
- 네이버: `nmap://search?query={encodeURIComponent(roadAddress)}&appname=kr.masscom.wolgye` → 실패하면 `https://map.naver.com/p/search/{encodeURIComponent(roadAddress)}`.
- 카카오: `kakaomap://search?q={encodeURIComponent(roadAddress)}` → 실패하면 `https://map.kakao.com/?q={encodeURIComponent(roadAddress)}`.
- `Linking.openURL`의 거절을 잡아 웹 주소로 넘어간다. `canOpenURL`은 Android 패키지 가시성 선언이 필요해 쓰지 않는다.
- `merchant.demo === true`이면 `길찾기` 대신 "가상 위치라 길찾기를 할 수 없어요"를 보이고 버튼을 두지 않는다(정직성).
- URL 조립은 순수 함수(`src/screens/town-map/directions.ts`)로 두고 한글·공백·특수문자 인코딩과 가상 점포 차단을 단위 시험한다.

## 5. 데이터

- 기존 공개 점포 목록(`/merchants`)과, 로그인 상태면 기존 도감(`/collection`)의 방문 점포 ID만 쓴다. 새 API·DB 변경 없음.
- 방문 여부는 도감의 인정된 방문 기준(도장판과 같은 `collection-stamps.ts` 모델)으로 계산한다.

## 6. 범위 밖

- 실제 지도 SDK·좌표·현재 위치·거리 계산, 확대·축소, 경로 안내(외부 앱이 한다).
- 점주가 핀 위치를 고르는 기능.

## 7. 시험과 증거

- 단위: 자리 배정 결정성·충돌 처리·8곳 초과, 길찾기 URL 인코딩·가상 점포 차단, 핀 라벨.
- 소스: 탭 구성(지도 탭 추가, 내 정보 숨김 유지), 지도 화면 동작 줄이기 분기.
- 모바일 전체 시험·타입·린트·운영/시연 export, 에뮬레이터 라이트·다크·글자 200% 지도 화면, 실폰에서 네이버/카카오 앱 또는 웹 열림.

## 8. 함께 고치는 결함

- 실제 휴대전화(SM-S928N, 411dp)에서 도장판 가게 이름 "가상 점포 A"의 두 번째 줄("A")이 잘려 보인다. 같은 폭의 "가상 점포 B"는 한 줄에 들어간다. 굵은 글자(800)의 측정·렌더 폭 차이로 보이며, 이름 칸에 여유 폭과 `textBreakStrategy="simple"`을 주고 실폰에서 확인한다.
