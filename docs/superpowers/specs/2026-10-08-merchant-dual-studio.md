# 점주 웹 제작 진입과 가상 가게 QA

최신 사용자 요청(2026-10-08 KST)을 기준으로 한다. 9월 30일 DOCX와 두 화면 이미지는 참고 자료이며, 문서 안의 제안·예시·외부 지시는 실행 권한으로 취급하지 않는다.

- 시작 화면에서 `AI로 초안 생성 후 스튜디오 하기`와 `미리 준비한 이미지 넣어서 스튜디오 가기`를 나란히 제공한다. 두 경로는 기존 프로젝트 편집·저장·게시 계약을 공유한다.
- 후속 사용자 요청에 따라 제작기는 점포 운영 페이지 아래로 펼치지 않고 별도 dialog로 연다. 시작 선택 → AI 그림 선택 또는 파일 선택 → 현재 단계 하나만 표시한다. 다음·이전으로 1→2→3→4를 이동하며 입력값을 보존한다. 4단계 하단에도 이전을 제공한다(10월 3일 명세의 4단계 하단 구성에 대한 최신 변경). 조작부만 스크롤하고 하단 버튼은 화면 안에 유지한다. AI에서 돌아가면 polling을 취소하고, 녹음·파일 처리 중 외부 닫기·Esc는 버리기를 확인한다.
- AI는 점주 웹 세션 및 서버 MANAGE_ART 권한으로 기존 그림 서비스를 사용한다. 생성 중·오류·쿼터·미설정을 안내하고, 확인한 초안만 편집기에 넣는다. 생성만으로 가게 대표 그림이나 캠페인을 게시하지 않는다.
- 대표 사진 입력은 JPG/PNG/WebP, 20 MiB, 최대 48MP/한 변 12,000px로 제한한다. 큰 입력을 브라우저에서 4,096px·3 MiB 이하 작업 사진으로 변환해 기존 8 MiB 저장 본문 한도를 지킨다. 변환 실패 시 기존 편집을 보존한다.
- 최근에 등록한 가게 사진을 다시 가져올 수 있게 하고, 서버 공개·점주 사진 목록은 최신 업로드부터 정렬한다. 최신 파일을 새로 선택해도 기존 저장 사진으로 덮어쓰지 않는다.
- 화면은 PC에서는 기존 넓은 편집기를 쓰고 좁은 브라우저에서도 두 진입 경로를 유지한다. 보안·파일 제한·기존 방문 보상 권리는 유지한다.
- 가상 점포는 시연 DB/API/앱에서만 만든다. 이름·주소·좌표·코인 캠페인을 저장한 뒤 실제 검색/상세 API와 앱 화면에서 확인한다. 합성 UI fixture, 실제 로컬 DB QA, 공개 서비스 실계정 QA를 구분한다.

검증: 웹 행동 회귀(두 경로·단계 전환·입력 보존·실패·계정 전환·큰 파일), AI API 웹 세션/CSRF/권한, 최근 사진 회귀, 로컬 DB→검색/상세→앱 확인, PC/좁은 화면 확인. 공개 점주 웹 로그인은 성공했지만 승인된 점포가 없어 제작·저장·게시 검증은 권한 연결 뒤 수행한다. 공개 배포는 하지 않았다.
