# 방문과 놀이를 잇는 MassCOM 경험

## 목적과 기준

사용자 요청: 수집품의 매력, 뽑기, 동행, 꾸미기, 서로 다른 미니게임 약 4종, 지속 목표, 개인 공유와 인스타 홍보, 가게 방문 흐름, 점주 편의와 실제 효과 분석을 하나의 사용 흐름으로 구현한다. 세부 장르·수치·구조는 사용자가 개발자에게 위임했다. 일부 영역을 후속 제안으로 넘기는 것으로 완료하지 않는다.

기준은 2026-10-04 조회한 origin/main `237d5471`이다. 작업 브랜치는 `feat/connected-play-collection`. 기존 방문 목표, 1/3/5회 수집품, 재질·봉투·뽑기 연출, 방문·쿠폰 취소, 점주 준비 체크리스트와 실제 집계는 재사용한다. 소유 내역·방문 보상·점주 권한·시연 격리를 보존한다.

## 경험 구조

- 홈의 동행 장면에서 내 공간과 놀이로 진입한다. 수집·뽑기 결과에서 공간에 놓기와 다음 가게 목표로 이어진다.
- 내 공간은 소유 수집품 최대 6개, 선택한 동행, 배경·배치·색 조합으로 구성한다. 서버에 저장하고 친구 관계 안에서 열람한다. 대표품은 실제 가게 상세로 연결한다.
- 미니게임은 타이밍 쌓기, 짝 찾기, 세 갈래 배달, 주문 맞추기의 네 종류다. 준비·규칙·플레이·결과·다시 하기·기록·해금을 모두 제공한다. 동행과 실제 수집 그림을 사용하며 미보유 그림은 게임 소재와 소유 상태를 혼동시키지 않는다.
- 서버가 실행의 seed와 제한 시간을 발급하고 입력 기록으로 점수를 재계산한다. 클라이언트 점수·재화·보상량을 신뢰하지 않는다. 같은 실행 완료 재시도는 같은 결과를 돌려준다. 게임 기록은 마일리지·쿠폰·방문 확정 보상을 발급하지 않는다.
- 게임 완주와 기록 도전은 공간 배경·장식을 해금한다. 방문·재방문·시리즈 목표는 실제 참여 중인 점포와 현재 진행에서 선택한다. 게임과 방문의 역할을 화면에서 명확히 구분한다.
- 뽑기는 기존 등급 선택과 미보유 보장 규칙을 지키면서 목표 캐릭터 미리보기, 획득 대상 중심 구도와 내 공간·동행 활용으로 강화한다. 소급 권리 변경이나 불필요한 중복을 도입하지 않는다.
- 개인 공유는 내 공간·동행·대표 수집품 중심의 피드/스토리 결과물을 제공한다. 외부 게시 완료를 측정했다고 주장하지 않는다. 서비스 홍보 이미지는 실제 앱 그림과 설치 안내를 사용하며 시연 화면의 성격을 표시한다.
- 점주 제작기는 실제 메뉴·점포 그림을 시작점으로 활용하고 방문 단계별 장면/소품 구성을 제안한다. 새 권한을 UI로 부여하지 않는다. 기존 확인·취소 동작은 유지한다.
- 사용 흐름 집계는 놀이 시작/완료, 공간 저장, 공유 열기/이미지 생성 등 측정 가능한 사건만 기록한다. 점주·운영자는 실제 방문/재방문/수집/쿠폰 집계와 구분해서 본다.

## 기술과 경계

기존 Expo 57, React Native, SVG, Reanimated, view-shot, PostgreSQL과 Node API를 사용한다. 새 의존성이나 유료 서비스를 도입하지 않는다. 게임은 물리 엔진이 필요한 장르를 피하고 시간·선택 입력으로 재현 가능한 규칙을 사용한다. 서버의 순수 규칙 모듈을 웹/Android 클라이언트에서도 공유한다.

새 데이터는 번호가 이어지는 additive migration에 넣는다. 계정 삭제 시 새 프로필·게임 기록도 정리한다. 보유 수집품과 동행은 서버에서 확인한다. 친구의 공간은 친구 관계가 유지될 때만 조회하며 계정 식별자·방문 시각·지갑 정보가 공유 이미지나 친구 응답에 노출되지 않게 한다.

## 완료 조건

1. 네 게임을 각각 시작·조작·종료·기록 저장·재도전할 수 있다.
2. 내 공간 저장과 재조회, 소유권 검증, 친구 공간 조회와 관계 차단이 작동한다.
3. 동행과 소장품이 홈·게임·공간·공유에 실제 자산으로 표시된다.
4. 실제 가게를 선택할 수 있는 지속 목표와 방문 후 연결이 있다.
5. 뽑은 캐릭터가 공간·동행으로 이어지고 기존 거래 보장이 유지된다.
6. 점주 제작기 시작 입력과 운영 지표가 실제 데이터에 연결된다.
7. 피드/스토리 공유 이미지와 홍보 결과물을 직접 렌더해 잘림을 검사한다.
8. API·PostgreSQL·모바일·사이트 검증과 웹/Android export, 작은 화면 시각/조작 확인을 수행한다. 배포·설치·기기 확인은 별도 상태로 기록한다.
