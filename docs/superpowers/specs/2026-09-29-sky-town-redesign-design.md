# 하늘 동네·여권 도장 디자인과 연출 개편 (Issue #224)

2026-09-29 소유자 피드백: "흰 바탕이라 밋밋하고 꾸민 느낌·기능이 없다", "DESIGN.md 제약 때문에 UI 품질이 낮다", "애니메이션이 있으면 좋겠다". 소유자는 네 개 하위 프로젝트를 **디자인 → 지도 → 친구 → 사장님 AI 시안** 순서로 진행하기로 했고, 이 문서는 첫 번째인 디자인·연출 개편만 다룬다. 방향은 소유자가 고른 **A 하늘 동네 + B 여권 도장**이다.

## 1. 목표와 성공 기준

- 첫 화면부터 "동네를 탐험하는 앱"으로 보인다: 흰 빈 화면 대신 하늘·동네 그림과 마스코트가 맞이한다.
- 도감은 도장이 찍히는 여권처럼 보여 모으고 싶어진다.
- 누르고, 들어오고, 바뀌는 순간마다 짧은 움직임이 있다. 동작 줄이기 설정에서는 모두 즉시 전환된다.
- 기존 기능·API·권한·정직성 규칙(가상 점포·앱 수집품·NFT 구분)은 바뀌지 않는다.
- 판정: 에뮬레이터·실폰 전후 화면을 소유자가 보고 "꾸민 느낌"을 판정한다(사용자 판정 필요). 자동 시험·명암비·export는 PASS여야 한다.

## 2. 그림 자산 (Codex 제작, D-045)

`apps/mobile/assets/images/mascot/v2/`에 기존 수채화 화풍과 같은 캐릭터 시트를 둔다.
- 투명 포즈 10종: `wave`(첫 화면), `explore-map`(탐색), `stamp`(방문 인증·도장), `gift`(보상 상자), `sleep`(빈 상태), `puzzled`(오류·오프라인), `friends`(친구, 후속), `search`(불러오는 중), `cheer`(메달 달성), `logo-badge`(앱 로고·아바타).
- 배경 2종: `sky-town-header`(화면 상단 하늘·동네, 아래가 흰색으로 사라짐), `town-map`(후속 지도용 일러스트).
- 앱에 넣는 파일은 긴 변 512px(배경은 1080px) 이하로 줄이고 색 수를 줄여 **포즈당 약 150KB, 전체 약 2MB 이하**를 목표로 한다. 원본은 저장소에 넣지 않는다.
- 생성 도구·프롬프트는 `v2/SOURCES.md`에 남긴다. 실제 점포 사진·보유하지 않은 수집품처럼 보이는 그림은 계속 만들지 않는다.

## 3. 시각 언어 (DESIGN.md 개정)

- **배경 층:** 화면은 하늘 그라데이션(`sky1 #BFE3FF → sky2 #E4F3FF → sky3 #F7FBFF`)으로 시작하고 상단에 `sky-town-header` 그림을 깐다. 콘텐츠는 그 위에 떠 있는 흰 카드로 올린다. 다크 모드는 밤하늘(`#1D3A63 → #1A2A45 → #182131`)과 같은 그림에 어두운 덧칠을 입힌다.
- **카드:** 흰색(다크 `#20252F`), 반경 24, 아주 옅은 파란 그림자(elevation 2~4). 목록 행은 카드, 설정 행은 묶음 카드.
- **포인트 색:** 행동은 기존 파랑 `#2456D6`, 보상·도장은 도장 주황 `#CA6E29`(다크 `#F0A057`)와 도장 잉크 `#A3401F`, 메달은 기존 브론즈·실버·골드. 새 색도 본문 대비 AA 4.5:1을 `styles.test`로 검사한다.
- **여권 페이지(B):** 도감의 스탬프 판은 크림 종이(`#F7EFE0`, 다크 `#2A2418`) 위 점선(`#A77C46`, 다크 `#8C6A3C`) 칸이다. 방문한 점포 칸에는 점포별로 조금씩 기울어진 원형 잉크 도장이 찍힌다. 기울기는 점포 ID에서 계산해 매번 같다.
- **글자:** 제목은 더 크고 굵게(화면 제목 28/800, 카드 제목 17/800), 본문 15~16. 글자 200%에서 잘리지 않는 기존 규칙은 유지한다.
- **브랜드:** 파란 네모 "masscom" 표식을 `logo-badge` + "월계 마스코트"로 바꾼다. 웹 머리글(#218)과 같은 이름이다. Android 아이콘 교체는 이번 범위 밖이다(스토어 자산·적응형 아이콘 검증이 따로 필요).
- **폐기하는 제약:** "라이트 배경 #FFFFFF", "절제된 파란 강조색만", "UI 작업에 새 의존성 금지(Expo 공식 모듈 포함)". 유지하는 제약: 정직성 문구, 명암비, 동작 줄이기, 터치 48dp, 지갑·권한 경계.

## 4. 연출 체계

새 의존성 없이 이미 있는 `react-native-reanimated` 4, `react-native-svg`, `expo-haptics`만 쓴다. `src/motion/`에 한곳으로 모은다.
- `useReducedMotion` 기반 공통 스위치: 켜지면 모든 연출은 즉시 최종 상태로 간다.
- **진입:** 목록·카드는 위로 12dp 떠오르며 나타난다(간격 50ms, 최대 8개까지만 지연).
- **눌림:** 카드·버튼은 0.96배로 줄었다가 스프링으로 돌아오고 가벼운 햅틱을 준다.
- **마스코트:** 숨쉬듯 1.00↔1.03배 반복(3초), 누르면 좌우로 한 번 흔들린다. 래스터 그림이라 눈 깜빡임은 하지 않는다.
- **하늘:** 구름 두세 개가 천천히(40초 주기) 옆으로 흐른다.
- **탭 바:** 선택된 탭 아이콘이 한 번 튀어 오르고, 가운데 도장 버튼은 누르면 도장처럼 눌린다.
- **새로고침:** 당겨서 새로고침하는 동안 `search` 마스코트가 흔들린다.
- 기존 축하·상자·쿠폰 연출(#216)은 그대로 쓰고, 축하에는 `cheer`를 더한다.

## 5. 화면 구조와 화면별 변경

- **하단 탭:** 기본 탭 바를 떠 있는 둥근 바로 바꾼다. 이번에는 `탐색 · (가운데 도장) 방문 인증 · 도감` 세 칸이다. `내 정보`는 각 화면 오른쪽 위 아바타(`logo-badge`)로 옮긴다. 후속 하위 프로젝트에서 `지도`와 `친구`가 들어와 다섯 칸(`탐색 · 지도 · 방문 · 도감 · 친구`)이 된다. 딥링크 `/settings` 경로는 유지한다.
- **첫 화면(역할 선택, 시연 앱):** 하늘 배경, `wave` 마스코트, "반가워요! 동네 탐험을 시작해요". 사용자·점주 카드는 떠 있는 흰 카드에 작은 마스코트 표식을 둔다.
- **탐색:** 상단에 인사·동네 이름 대신 "오늘은 어디를 탐험할까요?"와 `explore-map`을 둔다. 여권 진행 칩(메달 등급·배지 수)을 달고, 점포 카드는 시연 점포 그림 또는 이름 첫 글자 도장 표식을 쓴다.
- **방문 인증:** `stamp` 마스코트와 도장 카드 모양의 QR 패널. 기존 2분 QR·확인 코드·남은 시간 흐름은 바꾸지 않는다.
- **도감:** 여권 표지(기존 passport-hero를 하늘 배경 위로 이동) → 메달 선반 → 보상 상자 → 쿠폰 → **여권 도장 페이지** → 수집품·방문 기록 순서다.
- **내 정보:** 하늘 배경 위 프로필 카드(마스코트 아바타)와 묶음 설정 카드.
- **점포 상세:** 상단 그림(시연 점포 그림 또는 하늘 동네) + 도장 진행.
- **빈·오류·불러오는 중:** 각각 `sleep`, `puzzled`, `search` 마스코트와 한 줄 안내.

## 6. 공통 구성 요소 (`src/ui/`)

한 파일에 한 책임을 둔다. 화면은 이 조각을 조합만 한다.
- `SkyBackdrop`(그라데이션+헤더 그림+구름), `FloatingCard`(카드+눌림 연출), `BounceButton`(주·보조 버튼), `MascotPose`(포즈 이름→그림, 숨쉬기·흔들기), `StaggerList`(진입 순차 등장), `FloatingTabBar`(expo-router `tabBar` 교체), `StateScene`(빈·오류·로딩 마스코트 장면), `PassportStampPage`(여권 도장 판), `AppHeader`(제목+아바타).
- 색·반경·그림자·연출 시간은 `src/theme/world.ts` 한곳에 둔다. `palette.ts` 의미색은 유지하고 확장한다.

## 9. 후속 하위 프로젝트 결정 기록

- D-046 지도: 앱 안 일러스트 동네 지도(`town-map`)에 점포 핀·방문 도장을 띄우고, "길찾기"는 네이버·카카오맵 앱을 도로명 주소로 연다. API 키·비용 없음. 좌표 대신 지도 그림 위 상대 위치를 쓴다.
- D-047 친구: 친구 코드·QR로 서로 추가. 친구에게는 메달 등급·배지 수·가본 점포 스탬프만 보인다. 방문 날짜·시간은 비공개. 가게 추천 보내기와 친구 도감 순위를 둔다.
- D-048 사장님 AI 시안: 점포 등록 때 가게 이름·메뉴로 스탬프·수집품 그림 4안을 만들고, 사장님이 고르면 고해상도로 다시 생성해 손님 도감에 쓴다. OpenAI 이미지 API를 쓰며 키는 소유자가 서버 비밀 파일에 넣는다(장당 약 50~250원).

## 10. 구현 중 바뀐 점 (2026-09-29)

구현·에뮬레이터 확인 중 위 설계에서 아래처럼 바꿨습니다. 값과 구조는 코드(`apps/mobile/src/theme/world.ts`, `apps/mobile/src/ui/`, `apps/mobile/src/motion/`)가 정본이고 [DESIGN.md](../../../DESIGN.md)가 이 결과를 반영합니다.

- **색:** 도장 주황(라이트) `#E07A2E` → `#CA6E29`, 종이 선(라이트) `#B98A4E` → `#A77C46`. 도장 주황은 카드 위 3.3:1 이상·종이 위 3:1 이상, 종이 선은 종이와 카드 위 3:1 이상이 되도록 실제로 놓이는 면에서 다시 계산했다(`world.test.ts`). 다크 값은 그대로다.
- **머리글 글자 패널:** 머리글 그림은 불투명한 그림이라 글자가 그림 위에서 읽힌다고 보장할 수 없다(에뮬레이터에서 대비 부족 확인). 그래서 제목·부제를 반투명 패널(`headerScrim`, 라이트 `#F7FBFF`·다크 `#182131`, 알파 0.88) 위에 올리고, 검은색·흰색 그림 픽셀 위 최악 조합도 4.5:1 이상임을 시험한다.
- **스크롤 구조:** 설계의 `SkyBackdrop`은 화면에 고정된 배경(그라데이션+헤더 그림+구름)이었다. 화면마다 그림이 내용 위에 고정되거나 함께 스크롤되는 모습이 달라 일관되지 않아, **그림을 스크롤 내용의 머리글 안으로 옮겼다.** `SkyArt`(그라데이션·그림·구름)가 `AppHeader`·`BackHeader` 안에 들어 있고, `SkyScrollView`가 그 머리글을 스크롤 내용의 첫 요소로 둔다. `SkyBackdrop`은 페이지색(`sky[2]`)만 칠하는 루트로 줄었다. 그림 아래 15%는 페이지색으로 녹여 이음매 띠가 보이지 않게 했다.
- **BackHeader 추가:** 음식점 상세·다음 가게 추천·내 정보가 기본 흰 스택 머리글을 쓰고 있어 하늘 머리글(낮은 배너 + 둥근 뒤로 버튼)로 바꿨다. 개발용 역할 선택 시안은 기본 스택 머리글을 그대로 둔다.
- **연출 조각:** `MascotPose`는 `Mascot`, `StaggerList`는 `Stagger`가 됐다. 마스코트가 카드 안에서 눌림을 가로채지 않도록 누르면 흔들리는 반응은 홀로 선 히어로(`interactive`)만 갖는다. 진입 연출은 레이아웃 `entering` 대신 공유값 스프링이며 처음 8개 행만 연출하고 1.2초 뒤 최종 상태를 강제한다(에뮬레이터에서 방문 인증 탭이 한 번 빈 화면으로 보인 일이 있어 — 재현되지는 않았다 — 화면이 투명한 채 남는 경로를 없애기 위해).
- **동작 줄이기:** Reanimated는 시작 시 OS 값을 한 번만 읽으므로 `AccessibilityInfo`의 변경 이벤트를 함께 구독해 실행 중에도 따라간다. 동작 줄이기에서 눌림은 축소 대신 배경색 변화로 알린다.
- **도장 기울기:** 기울기(`stampTilt`)를 UI 런타임 워크릿 안에서 부르면 도감 탭이 충돌해, JS 쪽에서 계산해 넘긴다.
- **탭 바·상태 화면:** 탭 바는 키보드가 열리거나 숨은 경로(내 정보)에서 물러나고 화면은 바 아래 여유를 둔다. `StateScene`은 스스로 검증된 카드 면 위에 그려지고 오류는 다시 시도 버튼을 준다.
- **새로고침:** 당겨서 새로고침하는 동안 탐색 화면의 마스코트가 흔들리는 대신 `search` 포즈로 바뀐다.
- **자산 크기:** 마스코트 포즈 10종과 배경 2종의 합계는 약 1.3MB(`town-map` 포함)로 목표 2MB 이하다.
- **시험 규모:** 모바일 시험이 276개에서 347개가 됐다.
- **실폰:** 8절의 실폰(SM-S928N) 전후 화면은 이 브랜치에서 `NOT_RUN`이다. 에뮬레이터 확인은 [증거 폴더](../../evidence/sky-town-redesign-2026-09-29/README.md)에 있다.
