# 점주 수집품 제작기 폰 개편 설계 (Issue #329, 2026-10-03)

소유자 결정(2026-10-03): 제작기는 **점주 웹에 두고 폰 브라우저에 맞춘다**(앱 안에 넣지 않음). 방식은 **A "제자리 다듬기"**: 이미 있는 4단계 마법사(사진 배치 / 등급 미리보기 / 세부 조정 / 연출과 목소리)의 화면 배치만 시안 구조로 바꾸고, 데이터 모델·API·렌더러·회전 12프레임 계약은 바꾸지 않는다. 앱 하단 탭·하늘색 테마는 유지한다(고객 앱은 이번 범위 밖).

## 왜 하는가 (실측, main `b8d981d`, 390px, `tests/fixtures/collectible-qa-server.mjs`)

| 문제 | 실측 |
| --- | --- |
| 화면이 너무 길다 | 문서 높이 1단계 4,899px · 2단계 5,473px · 3단계 7,697px · 4단계 8,205px |
| 미리보기가 사라진다 | `.ce-preview`가 폰에서는 조작부 위의 일반 블록이라 스크롤하면 보이지 않는다 |
| 버튼이 쌓인다 | 초안 저장·이 결과 게시·게시 중지·삭제가 모든 단계 아래에 보인다 |
| 3단계가 1단계를 반복한다 | 자르기 캔버스와 확대·가로·세로 슬라이더가 3단계로 옮겨져 다시 보인다(`collectible-studio.mjs` `showStep`) |
| 여백이 이중이다 | 점주 페이지 카드(`#merchant-creator-editor`) 안에 스튜디오 카드가 다시 들어간다 |
| 두께가 숫자다 | 1~24 정수(기본 8), 실물 치수가 아닌 화면 측면 깊이(`COLLECTIBLE_CREATOR.md`) |
| 파형이 없다 | `<audio controls>`만 있고 `AnalyserNode`·파형 코드가 없다 |

## 성공 기준

- 390px에서 각 단계의 핵심 조작이 미리보기와 함께 보이고 하단 바가 항상 보인다.
- 게시·게시 중지·삭제는 4단계 하단 바와 머리글 "⋯" 메뉴에서만 보인다.
- 기존 저장·게시·재생·녹음 동작과 저장 형식이 그대로다(기존 초안·게시본이 그대로 열린다).

## ① 화면 뼈대

- **폰(≤820px) 편집 모드:** 스튜디오 홈에서 "새 수집품 만들기"나 기존 제작물을 열면 작업 영역(`ce-workspace`)이 화면 전체를 덮는 고정 레이어(`position: fixed; inset: 0`)가 된다. 점주 페이지의 다른 카드는 뒤에 남고 보이지 않는다. 스튜디오 홈 자체는 지금처럼 페이지 안에 둔다.
- **머리글(고정):** `← 스튜디오` · 단계 제목 · `n / 4` · "⋯" 메뉴. 단계 번호 버튼 4개는 머리글 아래 한 줄로 작게 유지한다(현재 단계 `aria-current="step"`).
- **미리보기(고정):** 2~4단계에서 머리글 아래에 붙는다. 고정되는 부분은 등급 칩(폰에서는 글자만) · 미리보기 캔버스(폰 높이 `min(30svh, 260px)`) · 재생/정지 아이콘과 회전 각도 한 줄뿐이다. 다시 보기·정면 보기·움직임 줄이기·설명·인사말 미리보기는 같은 영역의 접힌 "미리보기 옵션"(`<details>`)으로 옮긴다. 1단계는 자르기 캔버스가 미리보기 역할을 한다.
- **알림 줄:** 지금 페이지 위쪽에 있는 알림(`data-view="notice"`)은 폰 편집 모드의 고정 레이어에 가려지므로, 작업 영역에 있을 때는 하단 바 바로 위로 옮기고 스튜디오 홈에서는 홈 위로 되돌린다.
- **조작부:** 미리보기와 하단 바 사이에서만 스크롤한다.
- **하단 바(고정):** 1단계 `다음`, 2~3단계 `이전 / 다음`, 4단계 `전체 미리보기 / 게시하기`. 저장·게시 상태 문구(성공·오류)는 하단 바 바로 위 한 줄로 보인다.
- **"⋯" 메뉴(모든 단계):** 초안 저장 · 게시 중지 · 삭제. 삭제는 지금처럼 확인을 거친다.
- **폰 뒤로가기:** 작업 영역을 열 때 `history.pushState`로 상태를 하나 넣고, `popstate`가 오면 페이지를 떠나지 않고 스튜디오 홈으로 돌아간다(편집 내용은 메모리에 남고, 저장하지 않았다는 기존 안내가 보인다). 폰 중심으로 바꾸면 제스처 뒤로가기로 작업을 잃기 쉬워져서 넣는다.
- **데스크톱(>820px):** 지금 2열(조작부 + 고정 미리보기)을 유지하고 같은 하단 바·"⋯" 메뉴를 쓴다. 고정 레이어는 쓰지 않는다.

## ② 단계별 내용

펼친 곳에는 시안의 핵심 조작만 두고, 나머지는 HTML 기본 `<details>`("더 보기")로 접는다. 컨트롤은 지우지 않고 옮기기만 한다(기존 `data-*` 연결점 유지).

| 단계 | 펼쳐 둠 | "더 보기"로 접음 |
| --- | --- | --- |
| 1 사진 배치 | 사진 선택/바꾸기, 모양 3종(원형·우표·톱니), 캔버스 드래그, 확대 슬라이더와 −/+ 버튼 | 가로·세로 미세 이동(드래그를 못 하는 키보드·보조기기 사용자의 대체 수단이라 남긴다), 틀 채우기, 자동 맞춤, 자르기 적용·되돌리기·다시 실행 |
| 2 등급 미리보기 | 등급 칩(썸네일), 회전 각도, 표현 스타일 원본/음각/양각(묶음 버튼) + 깊이 슬라이더(지금은 3단계 "사진 세부 조정" 안에 있음 → 2단계로 옮김), 두께 얇게/보통/두껍게 | 등급 관리(이름·사용 여부·특수 등급 추가·설정 시작) |
| 3 세부 조정 | 되돌리기·다시 실행·원본과 비교 한 줄, 붓 도구 칸(사진 이동·잡티·투명·복원·색 통일)과 붓 크기·영역 색, 필터 선택(색 합치기·단순화·만화풍) + 고른 필터의 강도 슬라이더, 앞면·뒷면 스티커 | 밝기·대비, 단색 바탕, 사진 원본 색 반영, 붓 대상(패럴랙스)과 패럴랙스 조절, 사진 보정 초기화 |
| 4 연출과 목소리 | 움직임 템플릿 8종(격자), 효과, 적용할 등급(여러 개), 효과 대상, 인사말·MP3 올리기·직접 녹음 + **파형** + 재생, "게시 정보"(수집품 이름·시즌·캠페인·보상 등급 — 게시에 필요해 펼쳐 둔다) | 살아 있는 그림, 가게 이야기 |

- 필터 선택은 **보여 줄 슬라이더만** 바꾼다. 세 값(`merge`·`simplify`·`cartoon`)은 지금처럼 함께 저장·적용되고, 선택을 바꿔도 값은 그대로다. 처음에는 값이 0이 아닌 첫 필터, 모두 0이면 만화풍을 보여 준다.
- 되돌리기·다시 실행은 1단계 자르기 동작 줄에서 3단계 위쪽 줄로 옮긴다(같은 버튼을 두 곳에 두지 않는다).
- 3단계는 1단계의 자르기 조작(확대 줄·모양 타일·자르기 동작 줄)을 다시 보여 주지 않는다. 3단계 위쪽에 "사진 바꾸기·자르기는 1단계" 링크 버튼 하나만 둔다. 다만 붓·패럴랙스·living 영역·"원본과 비교"는 사진 캔버스에만 칠해지므로, 3단계 "붓 도구" 칸 위에 같은 사진 캔버스를 칠하는 면으로 보여 준다(`studio.mjs`가 캔버스만 단계에 맞춰 1단계 칸과 3단계 칸 사이에서 옮긴다). 3단계를 떠나면 붓은 "사진 이동"으로 돌아가 1단계에서 끌어도 지워지지 않는다(되돌리기 기록은 만들지 않는다). 폰 3단계에서는 칠하는 캔버스가 먼저, 동전 미리보기는 그 아래에 둔다. (2026-10-03 구현 중 보정: 붓 도구는 사진 캔버스에만 칠해진다)
- 수집품 이름은 1단계에서 4단계 "게시 정보"로 옮긴다. 새 초안은 지금처럼 기본 이름을 미리 채운다.
- 효과 대상·움직임 이름은 지금 모델이 가진 값만 쓴다(새 대상·새 템플릿을 만들지 않는다).
- 1단계 확대 −/+ 버튼은 0.25배씩 바꾸고 1~8배 범위를 넘지 않는다(되돌리기 기록에 남는다).

## ③ 새로 들어가는 것

- **묶음 버튼(세그먼트) 스타일:** 기존 `aria-pressed` 선택 타일(`.ce-choice`)을 가로 한 줄로 쓰는 CSS 변형. 새 컴포넌트 코드는 없다.
- **두께 3단계:** 얇게 4 · 보통 8 · 두껍게 14. 저장 값은 그대로 1~24 정수다. 기존 초안·게시본의 값이 셋 중 하나가 아니면 네 번째 버튼 "직접 지정 n"이 눌린 상태로 보이고, 값을 바꾸지 않는다. 변환은 순수 함수(`thicknessPreset(value)`·`presetThickness(name)`)로 모델 파일에 둔다.
- **파형:** 새 모듈 `apps/production-web/assets/collectible-waveform.mjs`.
  - `peaks(channelData, buckets)` 순수 함수: 구간마다 절댓값 최대치를 0~1로 돌려준다.
  - 그리기: `<canvas>` 막대, 재생 위치를 색으로 채운다(`timeupdate`).
  - 디코딩: `AudioContext.decodeAudioData`. 업로드·녹음은 손에 있는 `Blob.arrayBuffer()`를, 저장된 초안은 `data:` URL을 `atob`로 바이트로 바꿔 쓴다. **`fetch(data:)`를 쓰지 않는다**(CSP `connect-src`에 걸린다).
  - 디코딩이 실패하면(브라우저가 형식을 못 읽음) 파형만 숨기고 재생은 그대로 둔다.
  - `apps/production-web/server.mjs`의 정적 자산 허용 목록에 이 파일을 더한다.
- **밝은 작업면 유지:** 제작기 CSS는 흰 바탕 색을 직접 쓰고 디자인 토큰 검사(`tests/site/verify_design_tokens_test.mjs`) 대상도 아니다. 사이트 토큰 `--mc-*`는 다크 모드에서 밝은 색으로 바뀌어 흰 바탕과 대비가 깨지므로 연결하지 않는다. 대신 `.collectible-editor`에 `color-scheme: light`를 두어 다크 페이지 안에서도 입력창·선택창이 밝은 작업면으로 보이게 한다(사이트 토큰 전환과 제작기 다크 테마는 이번 범위 밖).

## ④ 하지 않는 것

- 데이터 모델, 저장 형식, 서버 API, 렌더러, 회전 12프레임 4×3 계약(Android `collectible-artwork.ts`·API `collectible-project-rules.ts`가 고정)
- 새 의존성(WebGL·three.js 등), 고객 Android 앱
- 한정 등급 기간(별도 Issue), 상점 v2(별도 Issue), 새 효과 대상·새 애니메이션
- 손가락 두 개 확대(핀치). 확대는 슬라이더·−/+로 한다.

## ⑤ 오류·상태

- 저장·게시 오류는 지금 문구를 그대로 쓰고 하단 바 위 상태 줄에 보인다(`role="status"`, 오류는 `role="alert"`).
- 녹음 권한 거부·용량 초과(1 MB·30초)·MP3 외 형식은 지금 메시지를 유지한다.
- 저장하지 않은 편집이 있을 때 스튜디오로 돌아가면(버튼·뒤로가기 모두) 기존 "아직 저장하지 않은" 안내를 보인다.

## ⑥ 검증

- **단위·DOM 시험(`tests/site/collectible-*.test.mjs`):** 위치만 바뀐 컨트롤은 같은 `data-*` 연결점으로 찾도록 기존 시험을 고친다. 새 시험:
  - 두께 변환(4/8/14 ↔ 얇게/보통/두껍게, 그 밖의 값은 "직접 지정"이고 값 보존)
  - `peaks()` (무음·최대값·버킷 수·빈 입력)
  - 단계별 노출: 게시·게시 중지·삭제는 4단계 하단 바와 "⋯" 메뉴에만 있다
  - 3단계에는 자르기 조작(확대·모양·자르기 동작)이 없고 사진 캔버스는 "붓 도구" 칸에 있으며, 1단계로 돌아가면 캔버스가 1단계로 돌아오고 붓이 "사진 이동"으로 되돌아온다
  - 뒤로가기(`popstate`)가 스튜디오 홈으로 돌아간다
- **회귀:** `node --test tests/site/collectible-*.test.mjs tests/site/verify_production_web_test.mjs`, `tests/site/verify_design_tokens_test.mjs`, `bash tools/gate.sh`.
- **화면:** QA fixture 서버로 360·390·412px와 데스크톱, 라이트·다크에서 4단계를 모두 열어 스크린샷으로 확인한다. 기준: 각 단계에서 미리보기·핵심 조작·하단 바가 한 화면에 보이는지, 버튼이 잘리지 않는지.
- **실기:** 점주 웹은 운영(`www.masscom.kr/merchant/`)에만 있고 운영에는 점포가 0곳이라 실제 제작기를 열 수 없다. 그래서 Samsung 폰 Chrome에서 `adb reverse tcp:4199 tcp:4199`로 로컬 QA fixture 서버를 열어 4단계를 넘기고, MP3 파형과 마이크 녹음 파형을 확인한다.
- **접근성:** 단계 전환 시 제목으로 포커스 이동(기존), `aria-current="step"`, "⋯" 메뉴의 `aria-expanded`, 묶음 버튼의 `aria-pressed`, 드래그 대체 슬라이더 유지.
