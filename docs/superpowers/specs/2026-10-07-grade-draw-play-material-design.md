# 등급 통합 뽑기·놀이·실물 재질 개선

2026-10-07 최신 사용자 결정: 브론즈 전체/실버 전체/골드 전체 풀마다 코인·테마 꾸미기·캐릭터 중 하나만 랜덤 지급한다. 놀이의 미완성 인상을 해소하고 프로젝트의 수집/방/가게 경험과 연결한다. 코인의 앞뒷면 모양과 기울기·재질 반사를 고친다. 기존 보유 권리·이미 발급된 가게권·점주 동의/쿠폰 한도는 보존한다.

## 뽑기

- 같은 등급의 전체 아이템 동일 확률. 보유 품목도 포함하며 중복 가능. 가격100/200/400P 유지. 테마 꾸미기는 기존 등급별 모자/소품/장식 중 개별 아이템 하나다. 추가 마일리지/의상/두 번째 보상은 지급하지 않는다.
- 코인은 실제 공개/활성/기간 내 현재 연결된 발행본의 1/3/5회 목표 등급을 브론즈/실버/골드로 읽는다. 가짜 코인·NFT 발행권·방문을 만들지 않는다. 기존 별도 이벤트 가게권의 고정 확률과 기한은 그대로 사용한다.
- GET /shop/draw-pools, POST /shop/draws {grade,requestId,expectedPoolVersion}; grade-draw.ts 계약. 서버 계정 잠금과 원장으로 한번 차감/한번 지급, 응답 유실은 같은 요청 재전송, 풀 변경은 차감 전 재확인. 기존 /shop/rerolls는 이전 앱/대기 구매 호환을 보존한다.
- migration0061의 별도 원장/코인 획득을 기존 잔액·캐릭터 소유·테마 장착·코인 수량/시리즈·계정 삭제에 연결한다. 최근20개 내역을 표시한다.

## 코인 재질과 놀이

- 실제 렌더 흐름을 확인해 앞뒷면 동일 외곽/알파 마스크, 넓은 손가락 기울기와 측면 두께를 적용한다. 반사는 각도와 조명 방향에 연속적으로 반응하고 금속/프리즘/진주 재질을 구분한다. 별도 반짝임만으로 재질을 대신하지 않는다. 모션 감소·접근성·실제 소유/발행 상태와 미디어 철회를 유지한다.
- 기존 네 놀이의 규칙/서버 판정·성과를 보존하며 보유 동행·공개 수집품과 방 탐험/꾸미기를 사용자 행동으로 연결한다. 구현되지 않은 액션·가짜 기록을 노출하지 않는다. 장면/입력/목표/결과/다시하기를 완성하고 기존 아트/색을 재사용한다.
- 추가 의존성 없음. 실제 폰/스크린샷과 visual verdict로 개선 전후를 확인한다. 코드/CI·합성QA·실기·실제 점주/쿠폰·공개 배포를 구분한다.

## 실행 소유와 검증

API 뽑기/0061/소유 합류, 모바일 상점/개봉, 컬렉션 재질/기울기, 놀이 네 흐름의 독립 소유자를 둔다. root는 server.ts/삭제/문서/통합 검증/서명된 비공개 설치/CI/병합 담당. 돈/중복/풀 변경/소유/미디어 회귀를 먼저 검사하고 전체 단위·PG·타입/lint/build와 독립 검토를 통과한다. 실기 기기 설정과 개인 데이터를 유지한다.
