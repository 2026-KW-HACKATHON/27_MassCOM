# 수집·게임·점주 운영 구현 계획

**목표:** 사용자 요청 1–14절을 기존 방문·수집·운영 구현에 연결해 구현과 실행 검증을 완료한다.
**설계:** [전체 범위와 경계](../specs/2026-10-05-collection-merchant-completion.md).
**기술:** Expo 57/RN/SVG/Reanimated, Node/pg/PostgreSQL, 기존 점주 웹, FCM HTTP v1, Android 미디어 인코더.

## 병렬 소유 범위

1. 점주 운영: merchant-operations 서비스와 migration0046, 권한 검사, 점주 웹, PostgreSQL/CSV 시험.
2. 알림: notifications 서비스와 migration0045, FCM 제공자/작업, 모바일 설정·함·토큰, 실제 배선과 인증 구분.
3. 꾸미기 데이터: collection-experience 서비스와 migration0044, 카탈로그/해금/장착/목표, 계정 삭제·친구 공개 회귀.
4. 고객 화면: 홈/동행/배지/상점/공간 장착·활용·다음 목표. 데이터 계약은 3번과 공유한다.
5. 네 게임: play-rules/서버 기록/게임별 성취·결과·보상. 해금 계약은 3번과 공유한다.
6. 영상·코인: 실제 영상 인코더/내보내기, 코인 재질과 제작기. 공유 화면 변경은 4번과 조정한다.
7. 주 작업자: HTTP·실행 서비스 배선/CSRF/동의/입력 검증, 로컬 환경·통합 시험·독립 리뷰, 문서·Git/PR 통합.
