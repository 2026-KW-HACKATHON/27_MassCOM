# 운영 관리자 기반 구현 순서

1. 기존 Google OIDC 세션과 계정 삭제 잠금·상점 공개 조건을 확인한다.
2. 실패하는 PostgreSQL/HTTP/웹 테스트를 추가한다.
3. 관리자 권한·감사 테이블과 상점 버전, 고정 OIDC 반환 위치를 마이그레이션한다.
4. 명시적 부여/회수 CLI, 요청 시 권한 검사, 비공개 상점 생성·수정·숨김을 연결한다.
5. `/admin/` 화면과 Caddy 허용 경로를 연결한다.
6. 타입 검사, 빌드, 단위·PostgreSQL·웹·Caddy 테스트로 확인한다.

중단 조건: 실제 운영 계정 권한 부여·배포는 동일인 확인과 별도 운영 승인 전까지 실행하지 않는다.
