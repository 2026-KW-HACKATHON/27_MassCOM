# 전체 경험 품질 실행 계획

[명세](../specs/2026-10-05-experience-quality.md)와 사용자 자율 진행에 따른다. 기존 동작의 회귀를 먼저 확인한 뒤, 게임·아트·화면 경계를 각각 책임 있게 바꾼다.

- [x] 최신 main/PR/요청·메모리·디자인/화면·규칙/자산의 현재 구조 확인, 최신 기반 브랜치.
- [x] 실제 변경 전 화면/설치 버전과 동작 기준 기록.
- [x] rulesVersion2와 과거 점수/권리 보존·서버/모바일 계약, 네 게임 동작/맥락/피드백 구현.
- [x] 캐릭터 행동 프레임·아이템/배지/팩 일러스트 생성과 공통 착용 합성, 소유/미리보기/획득/활용 연결.
- [x] 홈 위계·팩·꾸미기/장착·공간/친구·코인과 실제 이미지/영상 합성의 품질 보강.
- [x] 전체상태/작은화면/큰글자/다크/모션감소, 네게임/소유품/장비·PNG/MP4 실제 QA·반복수정.
- [x] 단위·실제DB·타입/lint/build·독립리뷰·sourcegate, 결과/한계 문서.
- [ ] Lore커밋·push·한국어PR·정확한HEAD CI·자율통합. 공개 배포/실폰 미실행 구분.

게임 변경은 새 버전의 실행에만 적용하고 이전 사용자 기록을 덮지 않는다. 기존 소유권·보상 정책·운영/시연 분리·FCM/점주 운영 기능은 보존한다. 신규 dependency는 기존 것이 해결하지 못할 때만 필요성을 검토한다.

실행 증거는 docs/evidence/experience-quality-2026-10-05/README.md를 따른다. sourcegate·GitHub 검사/통합 결과는 해당 브랜치 PR 기록으로 확인하며 미실행 실폰·공개 배포를 완료로 해석하지 않는다.
