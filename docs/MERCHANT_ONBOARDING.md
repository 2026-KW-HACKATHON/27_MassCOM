# 실제 점포 온보딩 안내 (운영자용)

플랫폼 관리자가 실제 점포를 SQL 없이 운영 관리자 웹(`https://www.masscom.kr/admin/`)에서 운영 시작하는 순서입니다. 결정은 [D-054](DECISIONS.md), 구현 선택은 D-055, 설계는 [점포 운영 시작 설계](superpowers/specs/2026-09-30-store-go-live-design.md)에 있습니다.

## 먼저 알아 둘 것

- **서비스에는 참조 번호만 남깁니다.** 동의서·확인 기록(종이·파일)은 운영자가 따로 보관하고, 관리자 웹에는 그 기록의 참조 번호만 적습니다. 사업자등록번호·대표자 이름·전화번호·이메일은 어떤 칸에도 적지 않습니다.
- 참조 번호는 영문·숫자로 시작하는 3~40자(영문·숫자·`.`·`_`·`-`)입니다. 하이픈·점·밑줄로 끊어도 숫자는 합쳐서 세므로 영문자 없이 이어지는 숫자는 모두 합쳐 7자리까지이고, 그보다 길면 전화번호·사업자등록번호로 보고 거절합니다(`CS-2609-01`은 6자리라 되고 `CS-2609-0101`은 8자리라 안 됩니다. 영문자가 사이에 있으면 따로 셉니다). 이메일·웹 주소 모양(`.kr`·`.com` 등)도 거절합니다. 날짜는 `2609`처럼 줄여 씁니다. 예: 점포 동의서 `CS-2609-01`, 점주 확인 기록 `OWN-2609-01`, 혜택 동의서 `OF-2609-01`.
- 모든 공개·숨김·점주 변경·혜택·캠페인 동작은 처리한 관리자와 함께 감사 기록에 남습니다. 관리자는 자기 계정을 점주로 올리거나 내릴 수 없습니다(다른 관리자가 처리).
- 운영 NFT는 발행 서버와 메인넷 승인 전까지 **발행 준비 중**입니다. 방문 보상 권리는 기록되고 고객 화면에는 "발행 준비 중"이 보입니다.

## 순서

1. **점포 등록(비공개).** "점포 등록" 양식에 점포 이름·소개·메뉴(`메뉴명 | 가격`)·점포가 확인한 영업시간·도로명 주소·최소 결제 금액을 적고 "비공개로 등록"을 누릅니다.
2. **메뉴·영업시간·주소 확인.** 점포 카드의 "점포 공개" 구역이 빠진 항목(메뉴 1개 이상·영업시간·도로명 주소)을 알려 줍니다. 빠진 것이 있으면 카드에서 고쳐 "수정 저장"합니다.
3. **점포 동의서 받기.** 점포가 가게 이름·사진 사용에 동의한 동의서를 받아 보관하고 참조 번호를 정합니다.
4. **점포 공개.** 카드의 "점포 동의서 참조 번호"에 번호를 적고 "점포 공개"를 누른 뒤 확인창에서 확인합니다. 공개한 뒤에는 메뉴·영업시간·주소를 비우는 수정이 거절되니, 비워야 하면 먼저 숨깁니다. 공개하면 고객 앱·웹 음식점 목록에 나오고 직원 등록을 받을 수 있습니다. 숨겼다가 다시 공개할 때도 참조 번호를 다시 적습니다.
5. **직원 등록 코드.** 점포 사람이 고객 Android 앱에 먼저 로그인한 뒤 `/merchant/`에서 이 점포를 골라 15분짜리 등록 코드를 받고, 확인된 연락 경로로 관리자에게 전달합니다([운영 직원 등록 절차](OPERATING_STAFF_REGISTRATION.md)).
6. **직원 승인.** 관리자 웹의 그 점포 "직원 권한"에 코드를 넣고 "이 점포 직원 승인"을 누릅니다.
7. **점주 확인.** 플랫폼 소유자가 그 사람의 **사업자등록증 원본**을 직접 확인하고, 사업자등록증·공개 정보에 있는 **점포 전화번호로 전화**해 그 사람이 점주(또는 점주가 정한 사람)인지 확인합니다. 확인 기록을 남기고 참조 번호를 정합니다(기록에는 사업자등록번호가 있어도 관리자 웹에는 번호만 적습니다).
8. **점주로 올리기.** 점주 변경은 **10분 안에 한 로그인**이 필요하니 오래 열어 둔 화면이면 로그아웃 뒤 다시 로그인합니다. 직원 행의 "확인 기록 참조 번호"에 번호를 적고 "점주로 올리기"를 누른 뒤 확인창에서 확인합니다. 점포당 점주는 최대 2명입니다. 점주를 바꿀 때는 "점주 목록 불러오기" 뒤 사유와 참조 번호를 적어 "직원으로 내리기"를 먼저 합니다(직원 권한은 남고, 완전히 빼려면 "권한 회수").
9. **보상 혜택(쿠폰).** 점주와 (1) 혜택 내용, (2) 비용은 점주 부담, (3) 유효 기간, (4) 발급 상한, (5) 중복 사용 정책을 모두 합의한 동의서를 받습니다. "보상 혜택(쿠폰)"에서 공개 중인 점포·상자·혜택 이름·설명·유효 기간·**발급 상한(필수, 1~10,000장)**·동의서 참조 번호를 적고 5항목을 모두 체크해 등록합니다. 상자마다 활성 혜택은 전체에서 하나입니다. 멈춘 혜택은 다시 켜지 않으니, 조건이 바뀌면 새 동의를 받아 새로 등록합니다.
10. **캠페인 공개.** "캠페인"에서 비공개 초안(첫·3·5회 수집품 이름, 기간)을 만들고 초안 줄의 "공개"를 누릅니다. 점포마다 공개 캠페인은 하나이고, 방문한 사람은 참여 등록 없이 누구나 보상을 받습니다(참여 정원은 화면에 보이는 숫자일 뿐, D-023). 멈출 때는 "중지", 다시 열 때는 같은 캠페인의 "다시 공개"를 씁니다.

## 멈출 때

- **점포 숨김:** 카드의 "비공개 및 신규 참여 중지". 유효한 미수령 QR이 있으면 수령·만료 뒤 다시 시도합니다. 숨기면 공개 캠페인은 중지·비공개가 되고 활성 혜택은 멈춥니다(이미 받은 쿠폰은 그대로 쓸 수 있음).
- **혜택만 멈춤:** 혜택 목록의 "혜택 멈춤". **캠페인만 멈춤:** 캠페인 목록의 "중지".

## 확인하지 않은 것

이 안내의 화면 흐름은 로컬 자동 시험(API·PostgreSQL·관리자 웹 가짜 DOM)으로만 확인했습니다. 운영 배포, 인증된 브라우저에서의 실제 점포 공개·점주 올리기, 실제 휴대전화의 "발행 준비 중" 화면은 `NOT_RUN`입니다([시험 상태](TEST_STATUS.md)).
