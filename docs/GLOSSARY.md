# 용어집

| 용어 | 이 프로젝트에서의 뜻 |
| --- | --- |
| 외부 지갑 | 사용자가 별도 앱에서 개인키와 자산을 관리하는 암호화폐 지갑 |
| 주소 확인 서명 | 자산 권한을 주지 않고 특정 주소를 제어함을 확인하는 메시지 서명 |
| nonce | 서명·요청 재사용을 막는 일회용 값 |
| 보상권 | 조건을 달성한 사용자가 앱 수집품 또는 NFT 발급을 요청할 수 있는 DB 권리 |
| NFT | 기존 블록체인에서 계약 주소와 token ID로 구분되는 수집품 |
| Outbox | DB 변경과 함께 저장해 장애 후에도 Worker가 재처리할 수 있는 작업함 |
| 멱등성 | 같은 요청을 반복해도 효과가 한 번만 발생하는 성질 |
| receipt | 체인 거래 실행 결과. 성공 표시만으로 올바른 NFT 발행을 증명하지는 않음 |
| 재조직 | 블록체인의 최근 채택 기록이 바뀌는 현상 |
| AAB | Google Play 제출용 Android App Bundle |
| APK | Android 기기에 직접 설치할 수 있는 패키지 |
