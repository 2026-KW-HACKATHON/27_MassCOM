새 기능 · 탐험 여권

방문이 도장이 되고, 도장이 메달이 됩니다.

점원이 확인한 방문만 셉니다. 메달 등급이 오르면 보상 상자가 열리고, 점주가 동의해 등록한 혜택만 쿠폰으로 나옵니다.

  1. 1방문 인증점원이 확인한 방문만, 같은 가게는 하루 한 번
  2. 2도장도감 스탬프판에 가게 도장이 찍힙니다
  3. 3 메달 등급 브론즈실버골드 동네 탐험가·단골손님·꾸준한 걸음, 세 메달
  4. 4보상 상자배지 3·6·9개마다 하나씩, 여는 것은 앱에서
  5. 5점주 동의 쿠폰매장에서 식별 QR을 보여 주면 점원이 사용 처리

실측 화면 안내 개발 빌드를 실제 휴대전화에서 로컬 API와 시연 가상 점포 데이터로 확인한 화면입니다(2026-09-29). 공개 서버 배포 전이며, 운영 DB에는 점주 동의 뒤 등록하기 전까지 혜택이 없습니다.
