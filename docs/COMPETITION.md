## 해석상 주의

- 원문은 HTTPS나 실제 휴대전화 검증을 직접 명시하지 않고 `로컬호스트나 로컬 IP 사용 유의`라고만 합니다. 외부 HTTPS·실기 검증은 더 강한 프로젝트 계약입니다.
- Android, Google Play, NFT, 블록체인은 대회 공통 규칙이 아니라 이 프로젝트의 선택입니다.
- 제출 파일 형식, 저장소 URL 제출 방법, 영상 형식은 이 자료에 없으므로 별도 공지를 확인해야 합니다.
