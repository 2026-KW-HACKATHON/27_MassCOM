# 핵심 도메인 불변조건

기술 스택과 정책 제안값이 확정되기 전에도 바뀌지 않는 안전 계약입니다.

1. 한 QR 수령 슬롯은 경쟁 요청에서도 최대 한 번만 방문과 보상 진행을 만듭니다.
2. 같은 사용자·캠페인·목표는 보상권을 최대 하나만 가집니다.
3. 보상권 소비와 발행 작업 생성은 같은 DB 트랜잭션에서 성공하거나 함께 취소됩니다.
4. 발행 작업은 요청 시점의 검증된 수령 주소와 지갑 연결 버전을 보존합니다.
5. 전송 응답을 잃으면 기존 reward key·거래·이벤트를 먼저 조회하며 새 키로 재발행하지 않습니다.
6. NFT 완료는 올바른 체인·계약·수령인·token ID·발행 이벤트가 모두 일치할 때만 기록합니다.
7. 누적 발행량은 소각이나 DB 상태 변경으로 줄지 않습니다.
8. 앱 수집품, 발행 접수, 체인 확인 중, 최종 완료를 서로 다른 상태로 표시합니다.
9. 사용자 개인키·복구 문구·주문번호·정확한 식사 시각은 공개 저장소·로그·온체인·IPFS에 기록하지 않습니다.
10. 지갑 연결 세션만으로 주소 통제 확인이나 NFT 수령 자격을 인정하지 않습니다.
