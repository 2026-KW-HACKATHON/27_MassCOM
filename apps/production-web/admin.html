운영 현황

실제 점포 최대 100곳의 현재 집계입니다. 방문은 유효한 기록, 보상은 취소되지 않은 기록만 셉니다.

새 점포는 비공개로 저장됩니다. 메뉴·영업시간·도로명 주소를 채우고 점포의 가게 이름·사진 사용 동의서 참조 번호를 적으면 공개할 수 있습니다. 점포를 숨기면 활성 캠페인의 신규 참여와 보상 혜택 발급도 중지됩니다. 유효한 미수령 QR이 있으면 숨김은 보류됩니다. 참조 번호에는 사업자등록번호·이름·전화번호를 쓰지 않습니다.

등록된 점포

보상 혜택(쿠폰)

탐험 여권 상자를 연 고객에게 주는 쿠폰입니다. 상자마다 활성 혜택은 전체에서 하나이고 공개 중인 점포만 고를 수 있습니다. 점주 동의 5항목을 모두 확인하고 동의서 참조 번호를 적어야 등록됩니다. 멈춘 혜택은 다시 켜지 않으며, 다시 제공하려면 새 동의를 받아 새로 등록합니다. 이미 발급한 쿠폰은 그대로 쓸 수 있습니다.

영문·숫자로 시작하는 3~40자(영문·숫자·., _, -)예요. 하이픈·점·밑줄로 끊어도 숫자는 합쳐서 세므로 영문자 없이 이어지는 숫자는 모두 합쳐 7자리까지예요(예: OF-2609-01). 사업자등록번호·전화번호·이름·이메일·웹 주소는 적지 마세요.

점주 동의 확인 (5항목 모두)

캠페인

초안은 비공개입니다. 공개 중인 점포의 초안을 공개하면 방문 보상이 시작되고, 점포마다 공개 캠페인은 하나입니다. 방문 보상에는 참여 등록이 필요 없어 방문한 사람은 누구나 받으며, 참여 정원은 화면에 보이는 참여자 수일 뿐입니다. 비용 상한은 쿠폰 발급 상한과 NFT 시리즈 상한이고, 운영 NFT는 발행 준비 중이라 권리만 기록합니다.

공개·중지된 캠페인

계정 삭제 요청

웹 Google 로그인으로 접수된 요청입니다. 접수 뒤 24시간 취소 기간이 지나야 처리할 수 있고 처리 기한은 접수 뒤 7일입니다. 계정은 마스킹한 표지만 보이며 이메일은 표시하지 않습니다. 본인 요청은 처리할 수 없습니다. 접수번호가 없는 옛 접수는 처리할 수 없으므로 접수한 사람이 다시 접수하거나 사유를 적어 거절해야 합니다. 거절 사유는 요청자가 접수번호로 그대로 봅니다.
