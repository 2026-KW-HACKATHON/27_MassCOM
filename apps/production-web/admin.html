흐름 지표

방문 인증 기준이며 매출과 다를 수 있어요

조회는 사람 수가 아니라 열람 횟수예요(조회와 방문은 같은 사람으로 연결하지 않아요)

새 점포는 비공개로 저장됩니다. 메뉴·영업시간·도로명 주소를 채우고 점포의 가게 이름·사진 사용 동의서 참조 번호를 적으면 공개할 수 있습니다. 점포를 숨기면 활성 캠페인의 신규 참여와 보상 혜택 발급도 중지됩니다. 유효한 미수령 QR이 있으면 숨김은 보류됩니다. 참조 번호에는 사업자등록번호·이름·전화번호를 쓰지 않습니다.

점포 등록

행정동 이름만 적어요(예: 월계동, 월계1동, 상계3·4동). 도로명·번지는 적지 않아요. 동네·업종은 공개 조건이 아니며 NFT 공개 정보(메타데이터)에 들어가고, 이미 발행한 NFT에는 발행 때 값이 그대로 남아요.

등록된 점포

보상 혜택(쿠폰)

탐험 여권 상자를 연 고객에게 주는 쿠폰입니다. 상자마다 활성 혜택은 전체에서 하나이고 공개 중인 점포만 고를 수 있습니다. 점주 동의 5항목을 모두 확인하고 동의서 참조 번호를 적어야 등록됩니다. 멈춘 혜택은 다시 켜지 않으며, 다시 제공하려면 새 동의를 받아 새로 등록합니다. 이미 발급한 쿠폰은 그대로 쓸 수 있습니다.

영문·숫자로 시작하는 3~40자(영문·숫자·., _, -)예요. 하이픈·점·밑줄로 끊어도 숫자는 합쳐서 세므로 영문자 없이 이어지는 숫자는 모두 합쳐 7자리까지예요(예: OF-2609-01). 사업자등록번호·전화번호·이름·이메일·웹 주소는 적지 마세요.

점주 동의 확인 (5항목 모두)

캠페인

초안은 비공개입니다. 공개 중인 점포의 초안을 공개하면 방문 보상이 시작되고, 점포마다 공개 캠페인은 하나입니다. 방문 보상에는 참여 등록이 필요 없어 방문한 사람은 누구나 받으며, 참여 정원은 화면에 보이는 참여자 수일 뿐입니다. 비용 상한은 쿠폰 발급 상한과 NFT 시리즈 상한이고, 운영 NFT는 발행 준비 중이라 권리만 기록합니다.

캠페인 이름은 발행하는 NFT의 공개 정보(메타데이터)에도 들어가고, 이미 발행한 NFT에는 발행 때 이름이 그대로 남아요. 개인정보·연락처는 적지 마세요.

캠페인 목적 (선택)

점주가 풀고 싶은 문제를 하나 고르면 조건이 목적에 맞게 정해져요. 목적형 캠페인은 점주 동의를 받은 활성 혜택을 등록한 뒤 공개할 수 있어요. 정하지 않으면 지금까지처럼 만들어져요. 공개한 뒤에는 목적과 조건을 바꿀 수 없어요. 앱에서 확인된 방문만으로는 "처음 오는 손님"인지 알 수 없어서, 첫 목적은 "MassCOM에서 처음 확인되는 방문"을 늘리는 것으로 적어요.

점주 동의 확인 (5항목 모두)

가게 연합미션

실제 점포 2~4곳을 묶고, 각 점주의 참여 동의 참조와 운영 점검을 확인한 뒤 공개합니다. 방문 순서는 자유이며 기간 중 각 점포에서 인정된 방문만 조각으로 셉니다. 완주하면 장면과 배지를 열 수 있고 쿠폰이나 무료 뽑기는 지급하지 않습니다. 점검 거리는 직선거리 스냅샷이며 도보 경로나 실시간 영업을 보증하지 않습니다.

운영 템플릿은 제목과 조각을 채웁니다. 참여 가게는 실제 등록 목록에서 직접 선택해 주세요.

이 미션은 시작 시각 이후 인정된 방문만 셉니다. 점주 동의 참조는 초안 저장 후 점주 채널에서 직접 등록하거나, 확인한 문서의 참조 번호를 운영자가 입력할 수 있어요. 참조 번호에는 이름·전화번호·사업자등록번호를 적지 않습니다.
