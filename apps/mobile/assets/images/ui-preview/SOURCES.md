# 로컬 UI 테스트 그림

2026-10-07 사용자가 확정한 MassCOM 최종 UI 이미지의 원본을 복사했다. `C:/Hack/ui-concepts-2026-10-07/final-all-pages`에서 생성한 built-in image_gen 결과이며 사용자가 해당 디자인의 구현을 요청했다.

이미지 파일 자체는 변경하지 않는다. React Native `Image`의 그림 영역만 레이아웃으로 표시하며 글자·버튼·입력·탭은 실제 컴포넌트다. Metro의 개발 전용 UI 진입점을 통해서만 참조하며 일반 운영/시연 번들에 합성 가게/프로필을 넣지 않는다.
